MCP คือช่องทางที่แอป AI อย่าง Claude หรือ ChatGPT ใช้คุยกับโปรแกรมอื่น เมื่อเปิดปลั๊กอิน MCP แล้ว แอป AI ที่คุณอนุญาตจะอ่านเว็บของคุณ และเขียนฉบับร่างไว้ให้คุณตรวจได้ แต่จะไม่เผยแพร่อะไรเลย สิ่งที่มันเขียนจะรออยู่เป็นฉบับร่างจนกว่าคุณจะกดเผยแพร่เอง

## AI ทำอะไรได้ และทำอะไรไม่ได้

แอป AI ที่เชื่อมไว้ทำสิ่งเหล่านี้ได้

- อ่านชื่อเว็บ ภาษา เขตเวลา และที่อยู่ของเว็บ
- ค้นบทความและหน้า รวมถึงฉบับร่าง
- ดูรายการบทความ หน้า หมวดหมู่ และรูปใน File Manager
- อ่านบทความหรือหน้าทั้งเรื่องในรูปแบบ Markdown
- สร้างบทความหรือหน้าใหม่เป็นฉบับร่าง หรือสร้างฉบับอีกภาษาของเรื่องที่มีอยู่
- แก้ฉบับร่าง ทั้งเนื้อหา ชื่อเรื่อง slug เกริ่นนำ ชื่อและคำอธิบายสำหรับผลค้นหา หมวดหมู่ และภาพปก

มันเผยแพร่ ตั้งเวลา เลิกเผยแพร่ หรือลบอะไรไม่ได้ และอัปโหลดรูปไม่ได้ ใช้ได้เฉพาะรูปที่อยู่ใน File Manager แล้ว และหมวดหมู่ที่มีอยู่แล้ว แตะเมนู redirect สไลด์ การตั้งค่า ปลั๊กอิน ความปลอดภัย หรือการอัปเดตไม่ได้ และไม่เคยเห็นรหัสผ่าน passkey หรือค่าที่ตั้งไว้ในปลั๊กอิน

ตอนเชื่อมต่อ คุณเลือกได้ว่าจะให้แอปเขียนฉบับร่างได้ หรืออ่านอย่างเดียว ส่วนค่า **อนุญาตให้ AI เขียนฉบับร่าง** ของปลั๊กอินจะหยุดการเขียนของทุกการเชื่อมต่อได้ทันที โดยไม่ตัดการเชื่อมต่อใด

### ย้อนฉบับร่างกลับ

เมื่อ AI แก้ฉบับร่าง TomeCMS จะเก็บฉบับก่อนหน้านั้นไว้ เปิดฉบับร่างนั้นในหน้าแก้ไข จะมีแถบด้านบนบอกว่าแอปไหนแก้และแก้เมื่อไร ปุ่ม **ย้อนกลับ** จะพาฉบับร่างกลับไปเป็นอย่างก่อนที่ AI เริ่มแก้ ถ้าคุณแก้ต่อเองหลังจากนั้น TomeCMS จะถามก่อน เพราะสิ่งที่คุณแก้จะหายไปด้วย

ย้อนได้หนึ่งขั้น ถ้า AI เขียนหลายครั้งติดกัน การย้อนกลับจะพากลับไปก่อนครั้งแรก ฉบับที่เก็บไว้จะหายไปเมื่อคุณย้อนกลับแล้ว เผยแพร่ฉบับร่างนั้น หรือลบมันทิ้ง

## ระหว่างที่คุณแก้ไข

คุณมาก่อนเสมอ ระหว่างที่คุณเปิดฉบับร่างอยู่ หน้าแก้ไขจะเช็กทุก 15 วินาทีว่ามีแอป AI อ่านหรือแก้ฉบับร่างนี้ในช่วง 3 นาทีที่ผ่านมาไหม ถ้ามี จะขึ้นแถบแจ้ง เช่น "Claude อ่านฉบับร่างนี้เมื่อ 1 นาทีที่ผ่านมา ระหว่างที่คุณเปิดหน้านี้อยู่ AI จะแก้ไม่ได้" ถ้าแถบ **ย้อนกลับ** ขึ้นอยู่แล้ว แถบนี้จะบอกแค่ "ระหว่างที่คุณเปิดหน้านี้อยู่ AI จะแก้ไม่ได้" เพราะอีกแถบบอกชื่อแอปไว้แล้ว

ตราบที่ฉบับร่างยังเปิดอยู่ คำขอแก้ของ AI จะถูกปฏิเสธ และ AI จะได้รับแจ้งให้ขอให้คุณปิดฉบับร่าง หรือสร้างฉบับร่างใหม่แทน ประมาณ 45 วินาทีหลังจากคุณปิดฉบับร่าง หรือสลับไปแท็บอื่น AI ก็แก้ได้อีกครั้ง ส่วนการอ่านฉบับร่างและการสร้างฉบับร่างใหม่ไม่ถูกปฏิเสธเลย

ถ้าฉบับร่างถูกแก้จากที่อื่น เช่นจากอีกแท็บหนึ่ง แถบจะขึ้นว่า "ฉบับร่างนี้ถูกแก้จากที่อื่น" พร้อมปุ่ม **โหลดฉบับล่าสุด**

## เปิดใช้งาน

ในหน้าผู้ดูแล เปิด **ปลั๊กอิน** แล้วเปิดสวิตช์ **MCP** การ์ดจะแสดงที่อยู่สำหรับใส่ในแอป AI คือ `https://<เว็บของคุณ>/mcp` พร้อมปุ่ม **คัดลอก** และรายการการเชื่อมต่อ

## เชื่อม Claude

บน claude.ai หรือ Claude Desktop

1. เปิด **Settings** แล้วไปที่ **Connectors**
2. เลือก **Add custom connector**
3. วาง `https://<เว็บของคุณ>/mcp` แล้วเพิ่ม
4. Claude จะเปิดหน้าผู้ดูแลของเว็บคุณ เข้าสู่ระบบถ้าจำเป็น
5. หน้าจอจะถามว่าจะเชื่อม Claude กับเว็บของคุณไหม ดูให้แน่ใจว่าที่อยู่ใต้ **การอนุญาตจะถูกส่งกลับไปที่** คือ `claude.ai` เลือกว่าจะให้เขียนฉบับร่างได้หรือไม่ แล้วกด **อนุญาตด้วย passkey** และยืนยันด้วย passkey

สำหรับ Claude Code ให้รัน

```sh
claude mcp add --transport http tomecms https://<เว็บของคุณ>/mcp
```

แล้วใช้คำสั่ง `/mcp` ใน Claude Code เพื่อเข้าสู่ระบบ การอนุญาตครั้งนี้ส่งกลับไปที่โปรแกรมบนเครื่องของคุณ หน้าจอจึงเตือนไว้ อนุญาตเฉพาะเมื่อคุณเพิ่งเปิดโปรแกรมนั้นเอง

## เชื่อม ChatGPT และ Codex

ในแอป ChatGPT บนเดสก์ท็อป (ที่มี Codex อยู่ด้วย)

1. เปิด **Settings** แล้วไปที่ **Plugins** แท็บ **MCPs**
2. กด **Add** แล้วเลือก **Add MCP server**
3. ตั้ง **Name** เช่น ชื่อเว็บของคุณ และเลือก **Type** เป็น **Streamable HTTP**
4. ใส่ `https://<เว็บของคุณ>/mcp` ในช่อง **URL** ช่อง **Bearer token env var** และรายการ header ทั้งสองส่วนให้เว้นว่างไว้ เพราะเว็บจะให้แอปล็อกอินเอง
5. กด **Save** รายการเว็บจะขึ้นในลิสต์พร้อมปุ่ม **Authenticate** ให้กดปุ่มนั้น
6. เบราว์เซอร์จะเปิดหน้าแอดมินของเว็บคุณ ล็อกอินถ้าจำเป็น แล้วอนุญาตด้วย passkey แบบเดียวกับข้างบน

แอปบนเดสก์ท็อปรับการอนุญาตกลับมาที่เครื่องของคุณเอง ใต้ **การอนุญาตจะถูกส่งกลับไปที่** จึงแสดงที่อยู่แบบ `127.0.0.1:49205` พร้อมคำเตือนว่าเป็นโปรแกรมบนเครื่องนี้ ซึ่งเป็นเรื่องปกติของแอปเดสก์ท็อป อนุญาตได้ถ้าคุณเพิ่งกด **Authenticate** เอง ตัวเลขหลังเครื่องหมาย `:` จะเปลี่ยนทุกครั้ง

ถ้าเชื่อมจาก ChatGPT บนเว็บผ่านหน้าตั้งค่า connector หรือแอป การอนุญาตจะถูกส่งกลับไปที่ `chatgpt.com` แทน ChatGPT เปลี่ยนชื่อเมนูเหล่านี้อยู่เรื่อยๆ ถ้าชื่อไม่ตรงกับที่เขียนไว้ ให้มองหาส่วนที่ใช้เพิ่ม MCP server หรือ connector ด้วยที่อยู่

## ตัวอย่างคำสั่ง

เมื่อเชื่อมแล้ว คุยกับแอป AI ได้ตามปกติ แอปจะเข้ามาที่เว็บเมื่อคำถามต้องใช้ข้อมูลจากเว็บ ให้ระบุว่า "บล็อกของฉัน" หรือชื่อเว็บ แอปจะได้รู้ว่าต้องดูที่ไหน ตัวอย่างเช่น

**ค้นหาและอ่าน**

- "ในบล็อกของฉันเคยเขียนเรื่อง passkey ไว้บ้างไหม ขอรายชื่อบทความพร้อมวันที่"
- "ฉบับร่างไหนบ้างที่ฉันไม่ได้แตะมาเกินหนึ่งเดือน"
- "อ่านบทความ *ย้ายมาใช้เซิร์ฟเวอร์ 1 GB* แล้วบอกว่าส่วนไหนเก่าแล้วบ้าง"
- "บล็อกของฉันมีหมวดหมู่อะไรบ้าง แต่ละหมวดมีกี่บทความ"

**เขียนฉบับร่างใหม่**

- "เขียนฉบับร่างบทความภาษาไทยเรื่องการสำรองข้อมูล VPS ยาวประมาณ 800 คำ ใช้น้ำเสียงแบบสามบทความล่าสุดของฉัน และใส่ในหมวด บันทึก"
- "เอาโน้ตนี้ไปทำเป็นฉบับร่างบทความ มีหัวข้อย่อยและข้อความย่อสั้นๆ: …"
- "สร้างฉบับร่างหน้าชื่อ *เกี่ยวกับ* จากข้อความนี้: …"

**แปล**

- "ทำฉบับภาษาอังกฤษของบทความ *ทำไมต้องทำลิงก์สั้น* เป็นฉบับร่าง คงหัวข้อและตำแหน่งรูปไว้เหมือนเดิม"

ฉบับแปลผูกกับบทความต้นทาง ทั้งสองภาษาจึงเชื่อมกันและใช้หมวดหมู่ร่วมกัน

**แก้ฉบับร่าง**

- "ในฉบับร่าง *ย้ายมาใช้ TomeCMS* ช่วยกระชับย่อหน้าแรกและแก้คำผิด ส่วนอื่นไม่ต้องแตะ"
- "ตั้งชื่อใหม่ให้ฉบับร่างเรื่อง Caddy ให้น่าอ่านขึ้น และเขียนคำอธิบายสำหรับผลค้นหาไม่เกิน 160 ตัวอักษร"
- "เลือกรูปจากคลังไฟล์ที่เข้ากับหัวข้อที่สองของฉบับร่างเรื่อง passkey แล้วใส่ให้"

**สิ่งที่แอปจะทำไม่ได้**

- "เผยแพร่ฉบับร่างเรื่องการสำรองข้อมูล" แอปเผยแพร่ไม่ได้ ให้เปิดฉบับร่างแล้วกดเผยแพร่เอง
- "ลบบทความเก่าเรื่อง 0.x" แอปลบอะไรไม่ได้
- "เอารูปจากเว็บนี้ใส่ในฉบับร่าง" แอปใส่ได้เฉพาะรูปที่อยู่ในคลังไฟล์แล้ว อัปโหลดรูปเข้าคลังก่อน แล้วค่อยสั่งใหม่

เคล็ดลับเล็กน้อย

- สั่งทีละฉบับร่าง และอ่านใน editor ก่อนเผยแพร่ทุกครั้ง
- ถ้าไม่ชอบที่แอปแก้ กด **ย้อนกลับ** ใน editor ฉบับร่างจะกลับไปเป็นเหมือนก่อน AI แก้
- ถ้าคุณแก้ฉบับร่างระหว่างที่แอปกำลังทำงานกับฉบับนั้น แอปจะรู้ว่าฉบับร่างเปลี่ยนแล้วและต้องอ่านใหม่ ไม่มีทางเขียนทับสิ่งที่คุณแก้

## ดูและตัดการเชื่อมต่อ

การ์ด MCP ในหน้า **ปลั๊กอิน** แสดงทุกการเชื่อมต่อ ทั้งชื่อแอป ปลายทางที่การอนุญาตถูกส่งไป สิทธิ์เขียน วันที่เชื่อม และครั้งล่าสุดที่ใช้ เครื่องหมายของ Claude หรือ OpenAI จะขึ้นที่นี่ และบนหน้าจอที่คุณอนุญาตการเชื่อมต่อ เฉพาะเมื่อเว็บของคุณตรวจสอบได้ว่าแอปนั้นคือใคร คือการอนุญาตถูกส่งกลับไปที่ claude.ai หรือ chatgpt.com หรือแอประบุตัวด้วยเอกสารไคลเอนต์ที่อยู่บน claude.ai หรือ chatgpt.com (ครอบคลุม Claude Code และ Codex)

แอปอื่นจะแสดงไอคอนคอมพิวเตอร์พร้อมชื่อที่แอปบอกมา และการอนุญาตที่ส่งไปยังโปรแกรมบนเครื่องของคุณจะขึ้นว่า "โปรแกรมบนเครื่องนี้" ปุ่ม **ตัดการเชื่อมต่อ** หยุดการเชื่อมต่อนั้นทันที ถ้าจะเชื่อมแอปนั้นอีก ต้องอนุญาตใหม่ด้วย passkey

การปิด MCP ทำให้เว็บหยุดตอบแอป AI ทันที และเมื่อเปิดอีกครั้งจะเริ่มใหม่หมด ทุกการเชื่อมต่อเดิมหายไป และต้องอนุญาตแต่ละแอปใหม่

## ความเป็นส่วนตัว

สิ่งที่เครื่องมือส่งกลับไปจะถึงบริษัทที่ให้บริการแอป AI นั้น และอยู่ภายใต้เงื่อนไขของบริษัทนั้น รวมถึงฉบับร่างที่ยังไม่ได้เผยแพร่บนเว็บของคุณด้วย เชื่อมเฉพาะแอปของผู้ให้บริการที่คุณยินดีให้เห็นบทความและหน้าของคุณ และตัดการเชื่อมต่อที่ไม่ได้ใช้แล้ว

## สำหรับแอป MCP อื่น

TomeCMS รับ Claude, ChatGPT และโปรแกรมบนเครื่องของคุณได้โดยไม่ต้องตั้งค่าอะไร แต่แอป AI อื่นอาจส่งการอนุญาตกลับไปที่อื่น ถ้าเชื่อมแล้วขึ้นว่าคำขอเชื่อมต่อไม่ถูกต้อง ให้เพิ่มที่อยู่ที่แอปนั้นใช้ในค่า **ที่อยู่ redirect เพิ่มเติม** ของปลั๊กอิน ซึ่งอยู่ใน **ตั้งค่า** บนการ์ด MCP ถ้ามีหลายที่อยู่ให้คั่นด้วยจุลภาค แต่ละที่อยู่ต้องเป็น `https` หรือเป็นที่อยู่บนเครื่องนี้ (`http://localhost` หรือ `http://127.0.0.1`)

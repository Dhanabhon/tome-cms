Sticky Banner ใส่แถบพาดไว้บนสุดของทุกหน้าสาธารณะ เหนือส่วนหัวของธีม ในแถบมีประโยคที่คุณเขียนแยกไว้สำหรับแต่ละภาษา และมีลิงก์ถ้าคุณใส่ไว้ เหมาะกับเรื่องที่อยากให้ผู้อ่านเห็นไม่ว่าจะเข้ามาที่หน้าไหน เช่น การปิดทำการช่วงวันหยุด หรือการย้ายไปที่อยู่ใหม่

## ตั้งค่า Sticky Banner

Sticky Banner ไม่มีการตั้งค่าที่ต้องกรอกก่อนเปิดใช้ การ์ดจึงขึ้นว่า "ปิด" แทนที่จะเป็น "ยังไม่ได้ตั้งค่า" กด "ตั้งค่า" บนการ์ด "Sticky Banner" กรอกสิ่งที่ต้องการ แล้วกด "บันทึก" จากนั้นจึงเปิดสวิตช์ หน้า [Cloudflare Turnstile](/tome-cms/th/plugins/turnstile/) อธิบายหน้าปลั๊กอินไว้

| การตั้งค่า | ในหน้าภาษาอังกฤษ | ใช้ทำอะไร |
| --- | --- | --- |
| "ข้อความ (อังกฤษ)" | "Message (English)" | ประโยคที่แสดงในหน้าภาษาอังกฤษ |
| "ข้อความ (ไทย)" | "Message (Thai)" | ประโยคที่แสดงในหน้าภาษาไทย ถ้าภาษาไหนเว้นว่างไว้ จะแสดงข้อความของอีกภาษาแทน ถ้าว่างทั้งสองช่องจะไม่มีแถบ |
| "ลิงก์" | "Link" | ไม่บังคับ ใส่เป็นพาธในเว็บนี้ เช่น `/contact` หรือที่อยู่ที่ขึ้นต้นด้วย `https` ถ้าเป็นอย่างอื่นจะถูกละเว้น และแถบจะแสดงโดยไม่มีลิงก์ |
| "ข้อความของลิงก์" | "Link text" | คำที่เป็นลิงก์ ต่อท้ายประโยค ลิงก์จะแสดงก็ต่อเมื่อมีทั้งที่อยู่และคำ |
| "ให้ผู้อ่านปิดแถบเองได้" | "Readers can close it" | เปิดไว้ตั้งแต่แรก ทำให้มีปุ่มปิดอยู่ท้ายแถบ ถ้าปิดตัวเลือกนี้ แถบจะแสดงค้างไว้กับทุกคน และหน้าเว็บจะไม่มีสคริปต์ของแถบเลย |
| "สีพื้นหลัง" | "Background" | สีของแถบ ตั้งต้นเป็นสีดำ |
| "สีตัวอักษร" | "Text" | สีของประโยคและลิงก์ ตั้งต้นเป็นสีขาว ให้เลือกสีที่อ่านออกบนพื้นหลัง คือสีอ่อนบนพื้นเข้ม หรือสีเข้มบนพื้นอ่อน |

ลิงก์มีได้ลิงก์เดียว ที่อยู่และคำของลิงก์จึงเหมือนกันในหน้าทั้งสองภาษา

## สิ่งที่ผู้อ่านเห็น

แถบอยู่บนสุดของหน้าแรก ทุกบทความ และทุกเพจ และเลื่อนหายไปพร้อมกับหน้าเมื่อผู้อ่านเลื่อนลง ภาพตัวอย่างธีมในหน้า "ธีม" ก็แสดงแถบนี้ด้วย

ถ้าเปิด "ให้ผู้อ่านปิดแถบเองได้" ไว้ แถบจะมีปุ่มปิดเป็นรูปกากบาท ซึ่งโปรแกรมอ่านหน้าจออ่านว่า "ปิดประกาศ" เมื่อผู้อ่านกด แถบจะเลื่อนหายไป หรือหายไปทันทีถ้าผู้อ่านตั้งเครื่องให้ลดการเคลื่อนไหว หลังจากนั้นแถบจะไม่ขึ้นอีกในทุกหน้าของภาษานั้นสำหรับผู้อ่านคนนั้น เมื่อคุณเปลี่ยนข้อความ แถบจะกลับมาให้ทุกคนเห็นอีกครั้ง เพราะสิ่งที่ผู้อ่านปิดไปคือข้อความเดิม

## สิ่งที่เก็บและส่ง

Sticky Banner ไม่ติดต่อบริการใดนอกเว็บของคุณเลย เมื่อผู้อ่านปิดแถบ เบราว์เซอร์ของผู้อ่านจะเก็บ `notice-` ตามด้วยตัวเลขที่คำนวณจากข้อความไว้ใน `localStorage` และไม่ส่งอะไรไปที่เซิร์ฟเวอร์ แถบที่ผู้อ่านปิดไม่ได้จะไม่เขียนอะไรเลย หน้า[สิ่งที่เบราว์เซอร์ของผู้อ่านเก็บไว้](/tome-cms/th/running/privacy/)รวมเรื่องนี้ไว้กับทุกอย่างที่เว็บเก็บไว้ในเบราว์เซอร์ของผู้อ่าน

Image lightbox ให้ผู้อ่านเปิดภาพในบทความหรือเพจดูแบบเต็มขนาด ภาพจะเปิดขึ้นทับบนหน้าเดิม และเมื่อปิด ผู้อ่านก็กลับมาอยู่ตรงที่อ่านค้างไว้

## เปิดใช้ Image lightbox

Image lightbox ไม่มีการตั้งค่าอะไร การ์ดขึ้นว่า "ปิด" ตั้งแต่แรก และเปิดสวิตช์ใช้ได้ทันที หน้า [Cloudflare Turnstile](/tome-cms/th/plugins/turnstile/) อธิบายหน้าปลั๊กอินไว้

## สิ่งที่ผู้อ่านเห็น

ในบทความหรือเพจ ภาพทุกภาพในเนื้อหาเปิดดูได้ รวมถึงภาพหน้าปกด้วย เมื่อเลื่อนเมาส์ไปบนภาพ ตัวชี้จะเปลี่ยนเป็นแว่นขยาย ผู้อ่านคลิกที่ภาพ หรือกด Tab ไปที่ภาพแล้วกด Enter หรือ Space ก็ได้

ภาพจะเปิดใหญ่เกือบเต็มหน้าต่าง ทับบนหน้าที่มืดลง พร้อมปุ่ม "ปิดภาพ" จะกด Escape หรือคลิกนอกภาพเพื่อปิดก็ได้ ภาพที่มีข้อความอธิบายภาพจะใช้ข้อความนั้นต่อใน lightbox ส่วนภาพที่ไม่มี โปรแกรมอ่านหน้าจอจะอ่านภาพนั้นในหน้าว่า "เปิดภาพขนาดเต็ม"

ภาพที่อยู่นอกเนื้อหา เช่น รูปของคุณในส่วนผู้เขียนท้ายบทความ จะเปิดแบบนี้ไม่ได้ ภาพปกของวิดีโอก็เช่นกัน กดแล้วจะเล่นวิดีโอแทน ส่วนหน้าแรกไม่มี lightbox และไม่โหลดโค้ดของมันเลย

## สิ่งที่เก็บและส่ง

Image lightbox ไม่ติดต่อบริการใดนอกเว็บของคุณ และไม่เขียนอะไรลงในเบราว์เซอร์ของผู้อ่าน lightbox แสดงภาพเดียวกับที่หน้าโหลดไว้แล้ว จึงไม่ต้องโหลดอะไรใหม่

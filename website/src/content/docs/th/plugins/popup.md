Popup เปิดกล่องขึ้นมาเหนือหน้าเว็บสาธารณะ ในกล่องมีหัวข้อ ข้อความสั้น ๆ และปุ่ม ใส่รูปด้วยก็ได้ กล่องจะขึ้นหลังรอไม่กี่วินาที หรือตอนผู้อ่านกำลังจะออกจากหน้า จะให้ขึ้นทุกหน้าหรือเฉพาะหน้าแรกก็ได้ เมื่อผู้อ่านปิดไปแล้ว กล่องจะไม่ขึ้นให้คนนั้นเห็นอีกจนกว่าคุณจะเปลี่ยนเนื้อหา

## ตั้งค่า Popup

Popup ต้องมี "ลิงก์ของปุ่ม" การ์ดจึงขึ้นว่า "ยังไม่ได้ตั้งค่า" จนกว่าจะใส่ลิงก์ กด "ตั้งค่า" บนการ์ด "Popup" กรอกเนื้อหาของภาษาเดียวหรือทั้งสองภาษา แล้วกด "บันทึก" จากนั้นจึงเปิดสวิตช์ หน้า [Cloudflare Turnstile](/tome-cms/th/plugins/turnstile/) อธิบายหน้าปลั๊กอินไว้

เมื่อเปิดใช้แล้ว แผงตั้งค่าจะมีปุ่ม "ดูตัวอย่างบนเว็บ" ซึ่งเปิดหน้าแรกพร้อม popup ที่เปิดค้างไว้ให้เลย แม้คุณจะเคยปิดมันในเบราว์เซอร์นั้นไปแล้วก็ตาม ระหว่างที่ปลั๊กอินยังปิดอยู่ แผงจะขึ้นว่า "เปิดใช้ปลั๊กอินก่อนจึงจะดูตัวอย่างบนเว็บได้"

| การตั้งค่า | ในหน้าภาษาอังกฤษ | ใช้ทำอะไร |
| --- | --- | --- |
| "รูปภาพ" | "Picture" | ไม่บังคับ กด "เลือกรูป" เพื่อเลือกรูปจากคลังไฟล์ และ "เอารูปออก" เพื่อเอาออก รูปจะอยู่ข้างข้อความ หรืออยู่เหนือข้อความบนมือถือ |
| "หัวข้อ (ไทย)", "หัวข้อ (อังกฤษ)" | "Heading (Thai)", "Heading (English)" | หัวข้อของ popup ในแต่ละภาษา ภาษาที่ไม่มีหัวข้อจะแสดง popup ของอีกภาษาแทนทั้งกล่อง จึงไม่มีทางที่หัวข้อภาษาไทยจะอยู่เหนือปุ่มภาษาอังกฤษ |
| "ข้อความ (ไทย)", "ข้อความ (อังกฤษ)" | "Message (Thai)", "Message (English)" | ไม่บังคับ ข้อความใต้หัวข้อ |
| "ข้อความบนปุ่ม (ไทย)", "ข้อความบนปุ่ม (อังกฤษ)" | "Button text (Thai)", "Button text (English)" | คำบนปุ่ม popup ของภาษาไหนจะขึ้นได้ต้องมีทั้งหัวข้อและคำบนปุ่ม |

| "ลิงก์ของปุ่ม" | "Button link" | ที่ที่ปุ่มพาไป ใช้ร่วมกันทั้งสองภาษา ใส่เป็นพาธในเว็บนี้ เช่น `/contact` หรือที่อยู่ที่ขึ้นต้นด้วย `https` ถ้าเป็นอย่างอื่น popup จะไม่แสดง ต้องกรอก |
| "ขึ้นเมื่อ" | "Opens" | "หลังรอสักครู่" (ค่าตั้งต้น) หรือ "ตอนผู้อ่านจะออกจากหน้า" การจะออกจากหน้าคือเมาส์เลื่อนออกทางขอบบนของหน้าต่าง ส่วนบนมือถือซึ่งไม่มีเมาส์ คือการเลื่อนอ่านเกินครึ่งหน้า |
| "รอ" | "After" | ใช้กับ "หลังรอสักครู่" เลือกได้ "5 วินาที" "10 วินาที" (ค่าตั้งต้น) หรือ "20 วินาที" |
| "หน้าที่ขึ้น" | "Pages" | "ทุกหน้า" (ค่าตั้งต้น) หรือ "หน้าแรกเท่านั้น" |

รูปต้องเป็นรูปในคลังไฟล์ที่พร้อมใช้แล้ว ระหว่างที่ popup ใช้รูปนั้นอยู่ คลังไฟล์จะไม่ยอมลบรูป แม้ปลั๊กอินจะปิดอยู่ก็ตาม ตามที่หน้า[คลังไฟล์](/tome-cms/th/admin/file-library/)อธิบายไว้

## สิ่งที่ผู้อ่านเห็น

popup เปิดขึ้นเหนือหน้าและทำให้สิ่งที่อยู่ข้างหลังมืดลง แต่จะไม่เปิดทับกล่องอื่น เช่น รูปที่เปิดด้วย [Image lightbox](/tome-cms/th/plugins/lightbox/) ถ้ามีกล่องอื่นเปิดอยู่ popup จะรอจนกล่องนั้นปิดก่อน

ผู้อ่านปิด popup ได้ด้วยกากบาทที่มุมกล่อง ซึ่งโปรแกรมอ่านหน้าจออ่านว่า "ปิดหน้าต่างนี้" ด้วยปุ่มปฏิเสธ ด้วยปุ่ม Escape หรือด้วยการคลิกนอกกล่อง การกดปุ่มหลักก็ปิด popup ไปพร้อมกับพาไปที่ลิงก์ด้วย ไม่ว่าจะปิดด้วยวิธีไหน เบราว์เซอร์ของผู้อ่านจะจำไว้ และ popup นั้นจะไม่ขึ้นให้ผู้อ่านคนนั้นเห็นอีก ถ้าคุณเปลี่ยนคำใดคำหนึ่ง ลิงก์ หรือรูป ก็จะนับเป็น popup ใหม่และขึ้นให้ทุกคนเห็นอีกครั้ง popup ภาษาไทยกับภาษาอังกฤษถูกจำแยกกัน

รูปใน popup เป็นแค่ส่วนตกแต่ง โปรแกรมอ่านหน้าจอจะข้ามไป เรื่องที่สำคัญจึงควรอยู่ในข้อความ ภาพตัวอย่างธีมในหน้า "ธีม" ไม่แสดง popup เลย

## สิ่งที่เก็บและส่ง

Popup ไม่ติดต่อบริการใดนอกเว็บของคุณ และรูปก็มาจาก storage ของคุณเอง เมื่อผู้อ่านปิด popup เบราว์เซอร์ของผู้อ่านจะเก็บ `popup-` ตามด้วยรหัสสั้น ๆ ที่คำนวณจากเนื้อหาของ popup ไว้ใน `localStorage` และไม่ส่งอะไรไปที่เซิร์ฟเวอร์ หน้า[สิ่งที่เบราว์เซอร์ของผู้อ่านเก็บไว้](/tome-cms/th/running/privacy/)รวมเรื่องนี้ไว้กับทุกอย่างที่เว็บเก็บไว้ในเบราว์เซอร์ของผู้อ่าน

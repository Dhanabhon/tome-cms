เมนู "สถิติ" เป็นรายการแรกใต้ "เนื้อหา" ใช้ดูว่าบทความและหน้าแต่ละหน้าถูกเปิดกี่ครั้ง และถูกอ่านจนจบกี่ครั้ง รวมทั้งดูว่าผู้อ่านมาจากไหน ใช้อุปกรณ์อะไร อยู่ประเทศไหน และอ่านภาษาอะไร TomeCMS นับทั้งหมดนี้เองเป็นยอดรวมรายวัน โดยไม่ใช้คุกกี้และไม่ส่งข้อมูลไปบริการภายนอก ตัวเลขเป็นค่าประมาณ ตามที่หน้านี้เขียนไว้ใต้หัวข้อ

ก่อนจะมีผู้อ่านคนแรกถูกนับ หน้านี้จะขึ้นว่า "ยังไม่มีผู้อ่านที่ถูกนับ" การนับเริ่มตั้งแต่รุ่น 0.11.0 ซึ่งเป็นรุ่นที่เพิ่มหน้านี้เข้ามา และนับย้อนไปถึงการเข้าชมก่อนหน้านั้นไม่ได้

![หน้า "สถิติ" ที่เลือก "30 วันล่าสุด" และ "ทุกภาษา" ไว้ ยอดเข้าชม 606 เพิ่มขึ้น 35% ยอดอ่าน 193 เพิ่มขึ้น 38% และอัตราการอ่าน 32% เพิ่มขึ้น 1 จุด ข้างล่างเป็นกราฟแท่งยอดเข้าชมและยอดอ่านรายวัน ตามด้วย "ผู้อ่านมาจากไหน" ที่มี "เข้าโดยตรง" และ news.example "อุปกรณ์" ที่มี "คอมพิวเตอร์" และ "มือถือ" "ประเทศ" ที่มีไทยและสหรัฐอเมริกาอยู่เหนือลิงก์ให้เครดิต DB-IP "ภาษา" ที่มีอังกฤษ และตาราง "บทความและหน้า" ที่มีบทความหนึ่งเรื่อง](../../../../assets/screenshots/th/stats.png)

## เลือกสิ่งที่จะดู

แถวแรกใช้เลือกช่วงเวลา คือ "7 วันล่าสุด" "30 วันล่าสุด" "90 วันล่าสุด" หรือ "12 เดือนล่าสุด" หน้านี้เปิดมาที่ 30 วัน และทุกช่วงสิ้นสุดที่วันนี้ตามเขตเวลาของเว็บ แถวที่สองใช้กรองทุกอย่างให้เหลือเฉพาะ "ไทย" หรือ "อังกฤษ" หรือเลือก "ทุกภาษา" เพื่อดูรวมกัน ทุกตัวเลือกจะอยู่ในที่อยู่ของหน้า เปิดจากบุ๊กมาร์กหรือลิงก์ที่แชร์ไว้ก็จะเห็นแบบเดิม

## ยอดรวม

ด้านบนของหน้ามีตัวเลขสามตัว

| ตัวเลข | นับอะไร |
| --- | --- |
| "ยอดเข้าชม" | จำนวนครั้งที่หน้าถูกเปิด |
| "ยอดอ่าน" | จำนวนครั้งที่บทความหรือหน้าถูกอ่านจนจบ |
| "อัตราการอ่าน" | ยอดอ่านคิดเป็นสัดส่วนของยอดเข้าชม |

ใต้ตัวเลขแต่ละตัวบอกว่าเปลี่ยนไปเท่าไรเมื่อเทียบกับช่วงเวลายาวเท่ากันก่อนหน้านี้ เช่น "↑ 35%" ส่วนอัตราการอ่านบอกการเปลี่ยนเป็นจุด จาก 31% เป็น 32% จึงขึ้นว่า "↑ 1 จุด" ถ้าช่วงก่อนหน้าไม่มีอะไรถูกนับเลย จะขึ้นว่า "ยังไม่มีช่วงก่อนหน้าให้เทียบ"

## กราฟและรายการ

"ยอดเข้าชมและยอดอ่านรายวัน" แสดงแท่งละหนึ่งวันตลอดช่วงเวลาที่เลือก โดยยอดอ่านอยู่ในแท่งเดียวกัน ถ้าเลือก "12 เดือนล่าสุด" กราฟจะเปลี่ยนเป็น "ยอดเข้าชมและยอดอ่านรายเดือน" กด "ดูเป็นตัวเลข" เพื่อดูตัวเลขชุดเดียวกันเป็นตาราง

ถัดมามีสี่รายการ เรียงตามยอดเข้าชม

- "ผู้อ่านมาจากไหน" บอกเว็บที่ผู้อ่านกดลิงก์มา "เข้าโดยตรง" คือการเข้าชมที่ไม่ได้มาจากลิงก์ไหน และ "เว็บไซต์นี้" คือการเข้าชมที่มาจากหน้าอื่นในเว็บของคุณเอง รายการนี้แสดงสิบเว็บที่ส่งผู้อ่านมามากที่สุด
- "อุปกรณ์" แบ่งยอดเข้าชมเป็น "มือถือ" สำหรับหน้าต่างที่กว้างไม่ถึง 768 พิกเซล และ "คอมพิวเตอร์"
- "ประเทศ" แสดงสิบประเทศที่มียอดเข้าชมมากที่สุด และ "ไม่ทราบ" สำหรับยอดเข้าชมที่หาประเทศไม่ได้
- "ภาษา" แบ่งยอดเข้าชมตามภาษาของหน้าที่ถูกเปิด

## บทความและหน้า

ตารางด้านล่างสุดแสดงทุกบทความและทุกหน้าที่ถูกนับในช่วงเวลานั้น พร้อม "ประเภท" "ภาษา" "ยอดเข้าชม" "ยอดอ่าน" และ "อัตราการอ่าน" หน้าแรกของเว็บนับรวมอยู่ในยอดรวม แต่ไม่มีแถวในตารางนี้ กด "ยอดเข้าชม" "ยอดอ่าน" หรือ "อัตราการอ่าน" ที่หัวตารางเพื่อเรียงจากมากไปน้อยตามค่านั้น ตารางแสดงทีละ 50 แถว และมี "50 รายการถัดไป" กับ "50 รายการก่อนหน้า" ไว้เปลี่ยนหน้า

กดชื่อเรื่องเพื่อดูบทความหรือหน้านั้นแยกออกมา จะเห็นยอดรวม กราฟ และรายการชุดเดียวกันเฉพาะของเรื่องนั้น และเลือกช่วงเวลาได้เหมือนเดิม "แก้ไข" เปิดเรื่องนั้นในหน้าแก้ไข ส่วน "ดูบนเว็บไซต์" เปิดเรื่องนั้นบนเว็บ และจะมีให้กดเฉพาะตอนที่เรื่องนั้นเผยแพร่อยู่บนเว็บ ลิงก์ "สถิติทั้งหมด" ใช้กลับไปหน้ารวม บทความที่ถูกลบไปแล้วยังเก็บตัวเลขไว้ และจะขึ้นชื่อว่า "ถูกลบแล้ว"

## อะไรถูกนับบ้าง

ยอดเข้าชมนับเมื่อผู้อ่านเข้ามาถึงหน้า การโหลดหน้าเดิมซ้ำ หรือกดย้อนกลับหรือไปข้างหน้าจนกลับมาที่หน้านั้น ไม่นับเป็นการเข้าชมอีกครั้ง ยอดอ่านนับเมื่อท้ายบทความขึ้นมาบนจอแล้ว และแท็บนั้นแสดงอยู่บนจอรวมกันได้ 15 วินาที

การเข้าชมบางแบบไม่ถูกนับเลย ได้แก่

- เบราว์เซอร์ของคุณเอง หลังจากเคยเปิดหน้าแอดมินในเบราว์เซอร์นั้นแล้ว
- ผู้อ่านที่เปิด Do Not Track หรือ Global Privacy Control ไว้
- โปรแกรมที่บอกตัวเองว่าเป็น bot
- การดูตัวอย่างธีม

ถึงอย่างนั้น คนที่ตั้งใจก็ยังเพิ่มตัวเลขได้ แต่ไม่เกิน 120 ครั้งในสิบนาทีจากที่อยู่ IP เดียว การนับไม่เขียนอะไรลงในเบราว์เซอร์ของผู้อ่าน และเซิร์ฟเวอร์ไม่เก็บข้อมูลที่ระบุตัวผู้อ่านคนใดไว้ หน้า[สิ่งที่เบราว์เซอร์ของผู้อ่านเก็บไว้](/tome-cms/th/running/privacy/) บอกว่ามีอะไรถูกส่งมาบ้าง และเซิร์ฟเวอร์เก็บอะไรไว้

## ประเทศมาจากไหน

ถ้า CDN ส่งประเทศของผู้อ่านมาใน header TomeCMS จะใช้ค่านั้น คือ `CF-IPCountry` หรือ header ที่ตั้งชื่อไว้ใน `TOME_CMS_COUNTRY_HEADER` ถ้าไม่มี จะค้นที่อยู่ IP ของผู้อ่านในฐานข้อมูลประเทศของ DB-IP Lite และถ้าไม่มีไฟล์นั้น ประเทศจะเป็น "ไม่ทราบ" ที่อยู่ IP ใช้ค้นในหน่วยความจำเท่านั้น และไม่ถูกเก็บไว้

ฐานข้อมูลนี้ติดมากับ image ที่ปล่อยออกมาพร้อมแต่ละรุ่น แต่การติดตั้งแบบปัจจุบัน build image บนเซิร์ฟเวอร์ของคุณเอง และ image นั้นจะไม่มีฐานข้อมูลจนกว่าคุณจะเพิ่มไฟล์เข้าไป ตามที่หน้า[การตั้งค่า](/tome-cms/th/running/configuration/) อธิบายไว้ที่ `TOME_CMS_GEOIP_PATH` DB-IP Lite ใช้สัญญาอนุญาต CC BY 4.0 และลิงก์ "ข้อมูลตำแหน่งจาก IP โดย DB-IP" ใต้ "ประเทศ" คือการให้เครดิตตามสัญญานั้น

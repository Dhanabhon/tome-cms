TomeCMS เป็นระบบจัดการเนื้อหา (CMS) สำหรับเว็บภาษาไทยและภาษาอังกฤษ สร้างด้วย Astro ตัวระบบเรนเดอร์หน้าเว็บสาธารณะบนเซิร์ฟเวอร์ และมีหน้าแอดมินที่สร้างด้วย React ไว้ให้เจ้าของเขียนงาน ส่วนเว็บหรือแอปที่ทำด้วยเครื่องมืออื่นก็ดึงเนื้อหาที่เผยแพร่แล้วชุดเดียวกันไปใช้ผ่าน REST API ได้

ระบบนี้ทำมาให้คนคนเดียวดูแล เว็บหนึ่งเว็บมีเจ้าของคนเดียว ซึ่งเข้าสู่ระบบด้วย Passkey และเป็นคนเดียวที่ใช้หน้าแอดมิน เจ้าของจะเขียนแค่ภาษาไทย แค่ภาษาอังกฤษ หรือทั้งสองภาษาก็ได้ เพราะบทความหรือเพจหนึ่งชิ้นมีได้ทั้งฉบับภาษาไทยและฉบับภาษาอังกฤษ

## ทำอะไรได้บ้าง

### การเขียน

editor มีสิ่งที่บทความต้องใช้ครบ ทั้งหัวข้อ รายการ ข้อความอ้างอิง โค้ด ตาราง รูป ลิงก์ และการจัดตำแหน่งข้อความ ลิงก์แต่ละอันเลือกได้ว่าจะให้เปิดในแท็บใหม่หรือไม่ ไฟล์จากคลังไฟล์ใส่ลงในบทความเป็นการ์ดให้ผู้อ่านกดดาวน์โหลด ส่วนไฟล์ PDF จะเปิดในเบราว์เซอร์แทน

บทความมีฉบับร่าง พรีวิว การตั้งเวลาเผยแพร่ และช่องข้อมูลสำหรับ SEO ฉบับภาษาไทยกับฉบับภาษาอังกฤษของบทความเดียวกันใช้หมวดหมู่ร่วมกัน นอกจากบทความแล้วยังมีเพจ และคุณจัดเมนูส่วนหัวกับส่วนท้ายได้เอง

คลังไฟล์เก็บรูปไว้รวมกับเอกสาร (PDF, Word, Excel, PowerPoint, CSV, ไฟล์ข้อความ และ ZIP) จัดเป็นโฟลเดอร์ได้ มีช่องค้นหาและตัวกรองตามชนิดไฟล์ ตัวไฟล์จริงเก็บอยู่ใน object storage ที่รองรับ S3

### การเผยแพร่

หน้าเว็บสาธารณะเรนเดอร์บนเซิร์ฟเวอร์ใหม่ทุกครั้งที่มีคำขอ เบราว์เซอร์ของผู้อ่านโหลด JavaScript เฉพาะของฟีเจอร์ที่เจ้าของเปิดใช้เท่านั้น

ที่อยู่ของบทความเป็นภาษาเดียวกับชื่อเรื่อง ชื่อภาษาไทยจึงได้ URL ภาษาไทย เมื่อเปลี่ยนที่อยู่ ที่อยู่เดิมจะ redirect ไปที่ใหม่แบบถาวร นอกจากนี้เว็บยังมี sitemap และ RSS feed

REST API ส่งกลับเฉพาะเนื้อหาที่เผยแพร่แล้ว และมีเอกสาร OpenAPI 3.1 อธิบายตัวเองไว้ ในโหมด headless TomeCMS จะซ่อนบล็อกของตัวเอง แต่ยังเปิดแอดมินกับ API ไว้ ให้เว็บอื่นดึงเนื้อหาไปแสดงแทน อ่านต่อได้ที่[ใช้งาน Headless API](/tome-cms/th/api/overview/)

### หน้าตา

TomeCMS มีธีมมาให้สองแบบ คือ `paper` และ `plain` ที่เรียบกว่า เลือกได้ที่เมนู "หน้าตาเว็บไซต์" พร้อมพรีวิวที่ใช้บทความของคุณเอง แต่ละภาษามีสไลด์หน้าแรกของตัวเอง แต่ละสไลด์มีรูป ข้อความสั้น ๆ และปุ่ม ธีมจะแสดงเป็นแบนเนอร์นิ่งหรือเป็นสไลด์เลื่อนก็แล้วแต่ธีม

ทั้งแอดมินและหน้าเว็บสาธารณะมีโหมดสว่างและโหมดมืด ผู้อ่านเลือกเองได้ เว้นแต่คุณจะปิดตัวเลือกนี้ เว็บมีโลโก้ของตัวเอง (ใช้ SVG ได้) จะมีโลโก้อีกชุดไว้ใช้ในโหมดมืดด้วยก็ได้ และมีไอคอนของเว็บ

### การเข้าสู่ระบบและปลั๊กอิน

ระบบนี้ไม่มีรหัสผ่าน เจ้าของเข้าสู่ระบบด้วย Passkey และเก็บ recovery code แบบใช้ครั้งเดียวไว้เผื่อวันที่อุปกรณ์หาย ตอนเปิดใช้ครั้งแรก ตัวช่วยตั้งค่าหกขั้นตอนจะพาตั้งค่าเว็บ และให้คุณเลือกที่อยู่ของหน้าแอดมินเอง

หน้าแอดมินแสดงเป็นภาษาไทยหรือภาษาอังกฤษตามภาษาหลักของเว็บ

ปลั๊กอินทำงานผ่าน hook ที่ตัวระบบกำหนดไว้ และทุกตัวปิดอยู่จนกว่าคุณจะเปิดเอง TomeCMS มีปลั๊กอินมาให้ห้าตัว ได้แก่ Cloudflare Turnstile ที่หน้าเข้าสู่ระบบ, Sticky Banner, Popup, Image lightbox และ Jev (TypeSafe AI) ที่ช่วยเสนอแนะระหว่างเขียน

### การดูแลเว็บ

Docker Compose รัน PostgreSQL กับ SeaweedFS ที่มากับระบบไว้เก็บไฟล์ หรือจะชี้การตั้งค่า S3 ไปที่ storage ภายนอกก็ได้ การสำรองข้อมูลเก็บฐานข้อมูลกับไฟล์มีเดียไว้ด้วยกัน และมีคำสั่งตรวจที่กู้ชุดสำรองลงคอนเทนเนอร์ชั่วคราวแล้วเทียบกับต้นฉบับ การติดตั้งทั้งเว็บบน VPS เครื่องเดียวมีสคริปต์ deploy ช่วยให้

ทุกคำขอเข้ามาที่ Node.js process เดียว ทั้งหน้าเว็บสาธารณะ หน้าแอดมิน API ของแอดมินเอง และ content API สาธารณะ การเข้าสู่ระบบด้วย Passkey ก็ทำงานอยู่ใน process นี้ ส่วนข้อมูลที่ต้องอยู่ถาวรเก็บไว้นอก process โดย PostgreSQL เก็บเนื้อหาและการตั้งค่า และ storage ที่รองรับ S3 เก็บไฟล์ บนเซิร์ฟเวอร์เครื่องเดียว storage นี้คือ SeaweedFS ที่มากับระบบ หรือจะใช้บริการภายนอกแทนก็ได้

ปลั๊กอินจะติดต่อบริการนอกเซิร์ฟเวอร์ก็ต่อเมื่อคุณเปิดใช้แล้วเท่านั้น Turnstile ตรวจการเข้าสู่ระบบกับ Cloudflare ส่วน Jev ส่งสิ่งที่คุณเขียนไปให้ TypeSafe AI ซึ่งจะเสนอหมวดหมู่ ประโยคสำหรับข้อความย่อ และคำอธิบายสำหรับผลค้นหา

ป้ายในแผนภาพเป็นภาษาอังกฤษ แผนภาพเดียวกันฉบับภาษาไทยอยู่ใน repository เป็นหน้าเว็บที่คลิกสำรวจได้ และมีมุมมองที่พาไล่ดูทีละเส้นทาง ที่ [docs/tome-cms-overview.html](https://github.com/Dhanabhon/tome-cms/blob/main/docs/tome-cms-overview.html) ดาวน์โหลดแล้วเปิดในเบราว์เซอร์ได้เลย

## สถานะก่อน 1.0.0

TomeCMS อยู่ที่เวอร์ชัน 0.11.0 และยังไม่มีรุ่น 1.0.0 สิ่งที่ติดตั้งได้ตอนนี้เป็นรุ่นพรีวิว สคริปต์ deploy จะ build แอปบนเซิร์ฟเวอร์ของคุณเองจากโค้ดที่ clone มา ส่วนการอัปเกรดคือการรันสคริปต์เดิมอีกครั้งจากโค้ดที่ใหม่กว่า

รุ่น 1.0.0 วางแผนไว้ให้ติดตั้งแบบ managed บน VPS เครื่องใหม่ ซึ่งเจ้าของกดติดตั้งอัปเดตที่ผ่านการตรวจสอบแล้วได้จากหน้าแอดมิน โค้ดส่วนนี้เขียนเสร็จและทดสอบกับชุดทดสอบในเครื่องแล้ว แต่ยังเหลือเงื่อนไขอีกสองข้อที่ repository ทำเองไม่ได้ ข้อแรกคือต้องมี release สาธารณะที่แก้ไขไม่ได้และตรวจ attestation ผ่าน ข้อที่สองคือต้องทดสอบรับบนเซิร์ฟเวอร์ HTTPS จริงให้ผ่านทั้ง `amd64` และ `arm64`

การติดตั้ง 0.x จะกลายเป็นแบบ managed บนเครื่องเดิมไม่ได้ ถ้าจะย้ายไป 1.0.0 ต้องใช้เซิร์ฟเวอร์ใหม่และย้ายเนื้อหาไปเอง ดูว่าอะไรเปลี่ยนบ้างได้ที่[ติดตั้งบน VPS](/tome-cms/th/start/install/)

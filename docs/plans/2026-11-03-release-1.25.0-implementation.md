# Post list block (1.25.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page can hold blocks that show hand-picked posts or a whole category, in a grid or a list, drawn with the active theme's own cards.

**Architecture:** A top-level Tiptap node `postList` stores the selection in `content_json` and leaves an empty placeholder `div` in `content_html`. The page routes resolve each node to posts at render time, and each theme splits its body at the placeholders and draws its own cards. Export, import and MCP treat the node like `video`, with its ids repointed on import. No migration.

**Tech Stack:** Astro 7 SSR, React admin, Tiptap 3.31.3, Kysely/Postgres, `node:test`, Playwright.

**Spec:** `docs/specs/2026-11-03-release-1.25.0-design.md`. Read section 1 first: those rulings are the owner's and are not open.

## Global Constraints

- No migration, no new dependency.
- Limits: at most 24 items per block; category default 6; layouts exactly `grid-2`, `grid-3`, `list`; a new block is `grid-3`.
- Placeholder is exactly `<div class="tome-post-list"></div>` in stored HTML.
- Pages only. Posts refuse the node.
- `PostLocale` is the language type; every new string goes in both `th` and `en`.
- Work on a branch `feat/post-list` in its own worktree from `origin/develop`. A fresh worktree needs `npm ci`.
- Git: never `git stash`; stage by explicit path; write the message to a scratchpad file and run `git commit -F <file>` as its own command with nothing chained; conventional commits; **no** `Co-Authored-By` or "Generated with" line (the repo hook rejects them).
- Run `npm run build` after any change to a `.ts` under `src/`, and read its output for warnings: a Tailwind optimize warning means a regex in `src/**/*.ts` was scanned as a class.
- E2E: at most 5 `/recovery` sign-ins per spec file; wait for hydration with `page.waitForFunction(() => !document.querySelector('astro-island[ssr]'))`.
- Leave no server or preview process running when a task ends.
- Public theme CSS: colours and spacing from existing tokens only; grid tracks are `minmax(0, 1fr)`.

## Review Focus

1. Two blocks in a row, with no text between: both draw, in order, and read as two lists. Pinned in Task 2 and Task 4.
2. A body that starts with a block, or holds only a block: no empty prose `div`, and `withLeadImage` does not touch a card's image. Pinned in Task 2 and Task 4.
3. A long Thai title in a narrow card at 320 px: the page does not scroll sideways. Pinned in Task 4.
4. A category renamed after the block was made: the block still shows it. Pinned in Task 2.
5. An MCP `update_draft` that moves a block: its attrs come back whole. Pinned in Task 6.

# TomeCMS 1.9.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the six items in the spec as 1.9.0:
- Gemini over MCP;
- File Manager rename;
- File Manager list view;
- an editor picture insert that keeps its place, plus Replace picture;
- confirming plugin switches;
- Paper's reading rail.

**Architecture:** Each task is self-contained.
- Server changes are kept to the MCP OAuth layer and the media service.
- UI changes reuse what exists: `confirmUi`, `MediaPicker`, the table bubble's pattern, and `BrandMark`.

**Tech Stack:** Astro 7, React, Tiptap 3, Kysely and Postgres, zod 4, `node:test`, Playwright. No new
dependency, no migration.

**Spec:** `docs/specs/2026-10-02-release-1.9.0-design.md`, plus the research note `docs/research/2026-10-02-gemini-mcp.md`.

## Global Constraints

- **Git:**
  - no stash;
  - stage by path;
  - put the commit message in a file and run `git commit -F` in its own call;
  - no attribution lines.
- **Release:** 1.9.0, with no migration and no new dependency.
- **The Gemini relay redirect rule:**
  - `https:`;
  - host exactly `oauth-redirect.googleusercontent.com`, with no port;
  - path matching `^/r/user_bound_custom-mcp-[A-Za-z0-9._-]+$`;
  - no query, fragment or userinfo.
- **DCR:**
  - `token_endpoint_auth_method` of `none`, `client_secret_basic` or `client_secret_post` registers as
    `none`, and the response says `none`;
  - anything else refuses.
- **Scope:** `offline_access` is accepted and ignored. Any other unknown scope refuses.
- **Marks:** a mark comes only from a host the app cannot choose. The relay redirect earns `gemini`,
  from `glincker/thesvg` `public/icons/gemini/default.svg`, unmodified except that a root fill moves
  onto the paths.
- **Rename:** `original_name` is trimmed, 1–255 characters, and keeps the original extension.
  `object_key` never changes.
- **Grid or List:**
  - `localStorage` key `tomecms.media.view`, values `grid` or `list`, default `grid`;
  - every read and write is inside try/catch.
- **Reading rail:**
  - current tick h2 2.5rem and h3 1.75rem, 3px, accent colour;
  - passed ticks in ink, ahead ticks muted;
  - animated with `transform: scaleX` from the inline end;
  - static under reduced motion.
- **Copy:** every new string in both `en` and `th` in `src/lib/admin-i18n.ts`, with natural Thai.
- **Tests:**
  - unit with `node --import tsx --test`;
  - integration with `node scripts/test-foundation.mjs <file>`;
  - e2e with `npm run test:e2e -- <spec>`, at most 5 `/recovery` sign-ins per spec file;
  - no test may depend on machine paths.

## Review Focus

1. **A look-alike relay host must not pass the Gemini redirect rule.** Try
   `oauth-redirect.googleusercontent.com.evil`, `evil.googleusercontent.com`, an uppercase host, and
   `/r/user_bound_custom-mcp-` with an empty id. Unit test in Task 1.
2. **Renaming a file to a name without its extension must keep it.** `photo` must become
   `photo.webp`. Unit test in Task 2.
3. **A picture inserted 3000px down a post must stay in view after the insert,** by both the upload
   path and the File Manager path. Browser test in Task 4.
4. **Replace picture, then Ctrl/Cmd+Z, must bring back the old picture in one step.** Browser test in
   Task 4.
5. **Cancelling a plugin confirm must leave the switch, and the server state, unchanged.** Browser
   test in Task 5.

### Task 2: Renaming a file in the File Manager

**Files:**
- Modify: `src/server/media/service.ts`. Find the function behind `saveMediaDraft`'s route (`PUT` or
  `PATCH` `/api/admin/media/[id]`) and accept an optional `name`.
- Modify: the route's zod schema, which gets `name: z.string().trim().min(1).max(255).optional()`.
- Modify: `src/lib/media-client.ts`. `MediaDraft` gains `name?: string`.
- Modify: `src/components/admin/MediaLibrary.tsx`. The detail editor gets a Name field. Find where
  alt text and folder are edited.
- Modify: `src/lib/admin-i18n.ts`: `media.name`, `media.nameHint` and `media.renamed`.
- Modify: the File Manager docs page, `website/src/content/docs/admin/file-library.md` and `th/…`,
  which gets a line on renaming.
- Test: `tests/unit/media-name.test.ts`, for the pure `keepExtension(newName, oldName)`; extend
  `tests/integration/media-service.test.ts`.

- [ ] **Step 1: Write `keepExtension` and its unit test**, in `src/lib/media.ts` or a new
  `src/lib/media-name.ts`.
  - `keepExtension('photo', 'a.webp')` is `photo.webp`.
  - `keepExtension('photo.png', 'a.webp')` is `photo.png.webp`. The extension is the stored type's;
    a different one is treated as part of the name.
  - `keepExtension('photo.WEBP', 'a.webp')` is `photo.WEBP`, compared case-insensitively.
  - `keepExtension('  x  ', 'a.pdf')` is `x.pdf`.
  - A file whose old name has no extension keeps the new name as given.
  - The result is cut to 255 characters with the extension still intact.
- [ ] **Step 2: Service and route.**
  - The update sets `original_name` through `keepExtension`, scoped to `owner_id`.
  - It never touches `object_key`.
- [ ] **Step 3: Integration test.** Rename an image used in a post's body and as its cover. The post's
  `content_html` is unchanged and still has `/media/<id>`. The media row has the new name and the same
  `object_key`. Another owner cannot rename it: the answer is 404.
- [ ] **Step 4: UI.**
  - The Name field sits beside alt text.
  - Saving shows the existing "Saved" state.
  - The card and the List row show the new name at once.
- [ ] **Step 5: Run and commit.**
  - Run the unit tests, `media-service`, `npm run check`, and the website check.
  - Commit message: `feat: rename a file in the File Manager without touching what already uses it`.

- [ ] **Step 2: CSS.**

```css
.reading-rail__link::before {
  transform-origin: right center; /* inline end in LTR; use logical where the codebase does */
  transition: transform var(--dur-short) var(--ease-out), background-color var(--dur-short) var(--ease-out);

.reading-rail__link[data-passed]::before { background: var(--color-ink); }
.reading-rail__link[aria-current="location"]::before {

}
.reading-rail__link--h2 { --rail-grow: calc(2.5 / 1.5); }
.reading-rail__link--h3 { --rail-grow: calc(1.75 / 1); }
@media (prefers-reduced-motion: reduce) {
  .reading-rail__link::before { transition: none; }
}
```

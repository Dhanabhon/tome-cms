# Release 1.16.0 (public page cache) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve public pages from an in-memory cache that an admin or MCP write clears at once, that expires on its own after 5 minutes or at the next scheduled post, and that makes a cached home page and post at least 5× faster.

**Architecture:**
- **The cache module.** One new module, `src/server/http/page-cache.ts`, holds three things: the key rule, a size-capped LRU with a generation counter, and `servePublicPage()`, which orchestrates a hit, a miss and a store. It has no database import; it gets the next scheduled moment through an injected function.
- **The middleware.** `src/middleware.ts` calls `servePublicPage()` first for `GET`/`HEAD`, and calls `invalidatePageCache()` after any `2xx` non-GET answer under `/api/admin/`.
- **MCP.** The two MCP write tools call `invalidatePageCache()` too.

**Tech Stack:** Astro 7 SSR (Node), TypeScript, Kysely/Postgres, node:test, Playwright.

**Spec:** `docs/specs/2026-10-04-release-1.16.0-page-cache-design.md`

## Global Constraints

**Process**
- Work in `.worktrees/release-1160`, on branch `feature/release-1.16.0`.
- Never `git stash`. Stage by explicit path.
- Write each commit message to a file and run `git commit -F <file>` as its own call.
- No Co-Authored-By or "Generated with" line; the repo's hook rejects attribution.
- `node_modules` is an untracked APFS clone. Never stage it.

**Tests**
- Unit: `node --import tsx --test tests/unit/<f>.test.ts`; all: `npm run -s test:unit`.
- Integration (Docker): `node scripts/test-foundation.mjs tests/integration/<f>.test.ts`.
- e2e: `npm run test:e2e -- tests/e2e/<f>.spec.ts --project=desktop`. At most 5 `/recovery` sign-ins per e2e spec file.

**Every task**
- `npm run -s check` and `npm run build` pass before every commit. Tailwind scans `src/**/*.ts`, so a class-like string in a `.ts` can break the CSS build.

**Cache values**
- TTL backstop: 5 minutes, `5 * 60_000` ms.
- Total cap: 32 MB, `32 * 1024 * 1024` bytes.
- Largest single entry: 2 MB, `2 * 1024 * 1024` bytes.
- All three are constants, with no setting and no env var.

**What is cached:** `GET`/`HEAD` that answer `200`, only when `TOME_CMS_FRONTEND_MODE` is `bundled`, for:
- `/th` and `/en` (with or without a trailing slash);
- `/th/blog/<slug>` and `/en/blog/<slug>`;
- `/th/<slug>` and `/en/<slug>`;
- `/rss.xml`, `/sitemap.xml` and `/robots.txt`.

**The key:**
- the path, plus `category` and `cursor` only, sorted;
- `utm_*` and every other parameter dropped;
- an empty value is absent;
- any `q` parameter, even empty, means no key.

**Never stored:**
- not `200`;
- a `Set-Cookie`;
- a `Cache-Control` containing `no-store` or `private`. The maintenance page and the signed-in owner's maintenance view both set one, which is how "nothing while closed" holds.

**Headers:**
- A hit or a miss that was stored answers with `ETag` (strong, a sha256 of the body, as `"<hex>"`), `Cache-Control: no-cache` and `X-Tome-Cache: hit|miss`.
- A matching `If-None-Match` answers `304` with no body.
- `HEAD` answers with no body.
- The stored headers are the response's, minus `set-cookie`, `date` and `content-length`.

**Invalidation:**
- A non-`GET`/`HEAD` request whose path starts with `/api/admin/` and whose answer is `2xx` clears the cache. A failed one does not.
- MCP `create_draft` and `update_draft` clear it after a successful write.
- The stats beacon (`POST /api/v1/stats/hit`) never does.

**Expiry:** the earlier of 5 minutes after storing and the next scheduled `published_at` after `now()` among published posts and pages.

**Scope:** no migration, no `/api/v1` change, no updater change, no Cloudflare/CDN work.

## Review Focus

1. **A render that streams.** Astro may stream the body. The miss path must read it in full before storing, and still return a working response to the reader. A body read twice (once to store, once to send) would hang or send nothing. Task 1 tests a `ReadableStream` body.
2. **An invalidation during a render.** If `invalidatePageCache()` runs while a miss is rendering, the entry must not be stored, or the old page comes back after the edit. Task 1 tests it with a render that invalidates midway.
3. **A response that may not be stored must stay untouched.** It must keep streaming, keep its own headers and get no ETag. This covers a `404`, a `500`, the maintenance `503`, an owner's `private, no-store` page and a `302`. Task 1 tests each.
4. **The trailing-slash and percent-encoded Thai slugs.** `/th/blog/%E0%B8%82…` and its trailing-slash form must not share a key with a different post, and must not crash `URL` parsing. Task 1 tests an encoded Thai path.
5. **The stats beacon and sign-in must not clear the cache.** Both are public `POST`s that answer `2xx`. Task 3 tests the beacon path and an `/api/auth/...` path.

```ts
import { createHash } from 'node:crypto';

/**
 * The public page cache: a rendered page kept in this process's memory, so the next reader of the
 * same address is answered without the database.
 *
 * Fresh because every write clears it (the middleware after an admin write, MCP after its own) and
 * because nothing lives past five minutes or past the next scheduled post going public -- the one
 * change no write announces. A render that an invalidation overtook is not kept, or the old page
 * would come back after the edit. One process holds it, so there is nothing to keep in step.
 */
export const PAGE_CACHE_TTL_MS = 5 * 60_000;
export const PAGE_CACHE_MAX_BYTES = 32 * 1024 * 1024;
export const PAGE_CACHE_MAX_ENTRY_BYTES = 2 * 1024 * 1024;

const LOCALIZED_HOME = /^\/(?:th|en)\/?$/;
const LOCALIZED_POST = /^\/(?:th|en)\/blog\/[^/]+\/?$/;
const LOCALIZED_PAGE = /^\/(?:th|en)\/(?!blog(?:\/|$))[^/]+\/?$/;
const FEEDS = new Set(['/rss.xml', '/sitemap.xml', '/robots.txt']);
const KEPT_PARAMETERS = ['category', 'cursor'] as const;
const DROPPED_HEADERS = new Set(['set-cookie', 'date', 'content-length']);

interface Entry {
  body: Uint8Array;
  etag: string;
  expiresAt: number;
  headers: Array<[string, string]>;
}

let generation = 0;
let totalBytes = 0;
// A Map keeps insertion order, so re-inserting on every hit makes its first key the least recently used.
const entries = new Map<string, Entry>();

export function pageCacheKey(url: URL): string | null {
  const path = url.pathname;
  if (!(FEEDS.has(path) || LOCALIZED_HOME.test(path) || LOCALIZED_POST.test(path) || LOCALIZED_PAGE.test(path))) return null;
  if (url.searchParams.has('q')) return null;
  const kept = KEPT_PARAMETERS
    .map((name) => [name, url.searchParams.get(name) ?? ''] as const)
    .filter(([, value]) => value !== '');
  return kept.length === 0 ? path : `${path}?${new URLSearchParams(kept).toString()}`;
}

export function pageCacheGeneration(): number {
  return generation;
}

export function invalidatePageCache(): void {
  generation += 1;
  entries.clear();
  totalBytes = 0;
}

export function resetPageCacheForTest(): void {
  invalidatePageCache();
  generation = 0;
}

function drop(key: string): void {
  const entry = entries.get(key);
  if (!entry) return;
  totalBytes -= entry.body.byteLength;
  entries.delete(key);
}

function keep(key: string, entry: Entry): void {
  drop(key);
  entries.set(key, entry);
  totalBytes += entry.body.byteLength;
  for (const oldest of entries.keys()) {
    if (totalBytes <= PAGE_CACHE_MAX_BYTES) break;
    drop(oldest);
  }
}

function storable(response: Response): boolean {
  if (response.status !== 200 || response.headers.has('set-cookie')) return false;
  const control = response.headers.get('cache-control') ?? '';
  return !/\b(?:no-store|private)\b/i.test(control);
}

function answer(entry: Entry, request: Request, state: 'hit' | 'miss'): Response {
  const headers = new Headers(entry.headers);
  headers.set('ETag', entry.etag);
  headers.set('Cache-Control', 'no-cache');
  headers.set('X-Tome-Cache', state);
  if (request.headers.get('if-none-match') === entry.etag) return new Response(null, { status: 304, headers });
  return new Response(request.method === 'HEAD' ? null : entry.body, { status: 200, headers });
}

export async function servePublicPage(input: {
  request: Request;
  url: URL;
  bundled: boolean;
  render: () => Promise<Response>;
  nextScheduled: () => Promise<Date | null>;
  now?: () => number;
}): Promise<Response> {
  const { request } = input;
  const now = input.now ?? Date.now;
  const key = input.bundled && (request.method === 'GET' || request.method === 'HEAD') ? pageCacheKey(input.url) : null;
  if (!key) return input.render();

  const known = entries.get(key);
  if (known && known.expiresAt > now()) {
    keep(key, known);
    return answer(known, request, 'hit');
  }
  if (known) drop(key);

  const started = generation;
  const response = await input.render();
  if (!storable(response)) return response;

  const body = new Uint8Array(await response.arrayBuffer());
  const headers = [...response.headers].filter(([name]) => !DROPPED_HEADERS.has(name.toLowerCase()));
  const scheduled = await input.nextScheduled();
  const entry: Entry = {
    body,
    etag: `"${createHash('sha256').update(body).digest('hex')}"`,
    expiresAt: Math.min(now() + PAGE_CACHE_TTL_MS, scheduled ? scheduled.getTime() : Number.POSITIVE_INFINITY),
    headers,
  };
  // An edit landed while this page was being drawn: what it drew may be the old version.
  if (generation === started && body.byteLength <= PAGE_CACHE_MAX_ENTRY_BYTES) keep(key, entry);
  return answer(entry, request, 'miss');
}
```

  Note: a miss that is not stored (over 2 MB, or overtaken by an invalidation) still answers with `ETag` and `X-Tome-Cache: miss`, because its body was read in full. That is correct: the ETag matches the body sent.

```ts
/**
 * When the next scheduled post or page goes public, or null when none is waiting.
 *
 * The page cache's one expiry no write announces: a scheduled post appears when its moment comes,
 * and nothing is written then, so a cached home page, feed or sitemap must not outlive it.
 */
export async function nextScheduledPublish(): Promise<Date | null> {
  const { db } = await import('../db/client');
  const result = await sql<{ next: Date | null }>`
    select min(published_at) as next from (
      select published_at from posts where status = 'published' and published_at > now()
      union all
      select published_at from pages where status = 'published' and published_at > now()
    ) as scheduled
  `.execute(db);
  return result.rows[0]?.next ?? null;
}
```

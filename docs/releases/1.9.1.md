# TomeCMS 1.9.1

Date: 2026-10-02
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.9.1 fixes two small things in the editor that were left over from 1.9.0. `/api/v1` is
unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no migration
  and no new setting, so the updater backs up the database alone.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.9.1.

## Fixes

- **A file put in at the end of a line no longer stays selected.** Before, the next key typed over
  the file card. Files now work the way pictures have since 1.9.0:
  - the caret moves to the start of the next line;
  - a new line is made only when nothing follows, or what follows is not a line of words;
  - the page scrolls only as far as it takes to show it.

  This applies from the + menu and from the / menu.
- **One Tab reaches the first button on the table bar and the formatting bar.** Before, Tab first
  landed on the bar's own box, which had no name and did nothing. The same fix covers the Replace
  picture bar, through one shared piece.

## Testing

- **Browser:**
  - a file put in mid-post and after the last line, then a key typed after it;
  - Tab from a selection to the formatting bar's first button;
  - Shift+Tab from the table bar's first button back to the editor.
- **Unit:** 928 tests.

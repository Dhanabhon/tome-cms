# TomeCMS 1.24.0

Date: 2026-10-13
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.24.0 lets you drag a file onto any media picker, and keeps select lists and the date and
time panel beside their field from the moment they open.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration; the latest is still
  `034_default_category_name`.
- **The updater and `tome`** are unchanged. Nothing to upgrade on the server.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.24.0.

## Added

- **Drag and drop on media pickers.** Every place that opens the media picker takes a file dragged
  from your computer: inserting an image or a file while writing, replacing an image, the cover
  image, your avatar, the maintenance picture, home slides and plugin images. Drop one file of the
  right kind and it uploads at once into the folder the picker has open, then comes back chosen,
  just as with the picker's Upload button.
  - Several files, a folder, or a file of the wrong kind upload nothing; the picker says why.
  - The picker takes no drop while it is uploading, or while another window is open on top of it.
  - A file dropped on the picker never lands in the post behind it.
- The File Manager works as in 1.23.0: a drop opens the upload window, and nothing is taken while any
  window is open on the page.

## Fixed

- **Select lists and the date and time panel** sit beside their field from the first frame, even
  when opened while a window or the settings drawer is still sliding in. Before, they appeared away
  from the field until the motion ended.

## Testing

- **Unit:** what a picker accepts from a drop, when a drop is refused, and where a panel goes inside
  a moving or scaling window.
- **Browser:** a PNG dropped on the editor's image picker uploads into the picker's folder and is
  placed once in the post; two files, a PDF on an image picker, and a drop under another window
  upload nothing; the File Manager's drops behave as before. A list and the date and time panel,
  opened with animations slowed tenfold, sit 4 px from their field while their window or drawer is
  still moving, ten times in a row. The full suite.
- **Operations:** the managed update and a restore.

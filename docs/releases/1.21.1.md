# TomeCMS 1.21.1

Date: 2026-10-07
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.21.1 fixes the installer's timezone list, keeps the chosen option in sight in every list,
and updates sharp for a security advisory in the image library it uses.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration; the latest is still
  `034_default_category_name`.
- **The updater and `tome`** are unchanged. Nothing to upgrade on the server.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.21.1.

## Security

- **sharp 0.35.5**, from 0.35.4. It brings a patched librsvg (libvips 1.3.4) for
  [GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w) (CVE-2026-96889, high).
  This is the update that matters for a running site: sharp reads every uploaded image, makes the
  smaller copies, and draws SVG brand images.
- **Also updated:** http-cache-semantics 4.3.0, source-map-js 1.2.2, smol-toml 1.9.0 and fast-uri
  3.1.8. The first and third run only while the site is built, source-map-js is loaded by the
  running site but the affected code is never reached, and fast-uri is a development tool.
- **Left as it is:** the production audit still reports eight advisories, all in Tailwind CSS 3 and
  the packages it uses. Tailwind runs only when the CSS is built, not in the running site, and its
  fix is Tailwind 4, which is a change of its own.

## Fixed

- **The installer's timezone list** opened partly below or beside the window on a desktop screen,
  so some choices could not be reached. The step's entrance animation kept its transform after it
  ended, and the list was placed against the step instead of the window. It now opens inside the
  window. Only a new install shows this screen.
- **Every list in the admin** keeps its chosen option in sight: when it opens on a choice far down,
  and as the arrow keys, Home, End or a typed letter move through it. A pointer moving over the list
  does not scroll it. The code block's language list is where this shows most.

## Testing

- **Browser:** the installer's timezone list opens inside the window at desktop size and its last
  option can be chosen; the code block's language list scrolls to a language past the fold with
  End.
- **Integration:** the image, brand, share-image and import tests with sharp 0.35.5.
- **Image:** the application image built for amd64 and arm64 loads sharp 0.35.5 and draws an SVG.
- **Operations:** the managed update and a restore.

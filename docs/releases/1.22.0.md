# TomeCMS 1.22.0

Date: 2026-10-08
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.22.0 moves its styles to Tailwind CSS 4 with no visible change, which clears the last
advisories from the production audit, and tidies how lists scroll.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration; the latest is still
  `034_default_category_name`. Only the application image changes.
- **The updater and `tome`** are unchanged. Nothing to upgrade on the server.
- **A build from source** upgrades by running the deploy helper again. Its dependencies changed, so
  it installs them afresh.

`deploy/cloud-init.yaml` now installs 1.22.0.

## Security

- **The production audit reports no advisory.** The eight left after 1.21.1 were all in Tailwind
  CSS 3 and the packages it used (braces, micromatch, chokidar, fast-glob, postcss-selector-parser,
  postcss-nested, @tailwindcss/typography). They ran only while the CSS was built, never in the
  running site. postcss-selector-parser is held at 7.1.6 or later under the typography plugin.

## Changed

- **Tailwind CSS 4** (4.3.3), from 3.4.19, through `@tailwindcss/postcss`. Every admin screen, the
  installer and the three themes were photographed before and after, at phone, tablet and desktop
  widths in light and dark, and compared pixel by pixel; nothing visible changed. To keep it that
  way, TomeCMS keeps Tailwind 3's reset (`src/styles/preflight.css`), its hover behaviour, and the
  typography plugin's Tailwind 3 greys. The built CSS keeps every scroll timeline, container query
  and dark and reduced-motion rule it had.

## Fixed

- **Lists** scroll to their chosen option the next time they open, even when the pointer moved over
  them as they closed, and Home and End now scroll to the very top and the very end, so the list's
  edges show.

## For theme authors

- Utility classes are Tailwind 4's. Classes Tailwind 4 removed (such as `bg-opacity-*`) are gone,
  and its renames apply (`shadow-sm` is now `shadow-xs`, `rounded-sm` is `rounded-xs`, `outline-none`
  is `outline-hidden`, `ring` is `ring-3`).
- `rounded-sm`, `ease-out` and `ease-in-out` resolve to TomeCMS's own tokens, not Tailwind's values.
- Tailwind still scans only `src/`, and the reserved theme ids are unchanged.

## Testing

- **Visual:** 472 screenshots of the admin, the installer and the three themes, before and after,
  compared pixel by pixel; every difference traced to a clock, a live check or a colour drawn at
  random for each run, and one anti-aliased edge off by 1/255.
- **Build:** the theme style sheets are byte for byte the same; the shared one lost no declaration.
- **Unit:** where a list scrolls for its first, last and middle rows.
- **Browser:** the full suite, with the list's Home and End and the installer's lists.
- **Operations:** the managed update and a restore.

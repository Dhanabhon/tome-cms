# TomeCMS 1.5.3

Date: 2026-09-30
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.5.3 shows a PDF's first page in the File Manager, lets a link in the editor point at a file
from the library, makes "Copy URL" copy an address that works anywhere, and links Paper's footer.
`/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no
  migration and no new setting, so the updater backs up the database alone. The admin gains one
  dependency, `pdfjs-dist`, loaded only when the File Manager draws a PDF.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.5.3.

## The File Manager

- **A PDF shows its first page.** Its card and its details show the first page, drawn in the browser
  with pdf.js as the card comes into view, two at a time, from a new owner-only route
  (`/api/admin/media/<id>/content`) that reads the file from storage on the application's own address
  and answers ranges, so a long PDF is not downloaded whole for one page. Until the page is drawn, or if
  it cannot be, the card keeps its "PDF" label. Other documents keep their labels.
- **"Copy URL" copies a full address**, such as `https://example.com/media/<id>`, which works wherever
  it is pasted; the field shows the same address. The button itself says "Copied" for two seconds, in
  place of a line of text under it.

## The editor

- **A link can point at a file from the File Manager.** The link dialog has "Choose from the File
  Manager": pick a document and the selected words link to it (with nothing selected, the file's name
  is inserted as the link). The link points at `/media/<id>`, so it keeps working if the site's address
  changes, and it remembers its file: the File Manager counts it as a use, and will not delete a file a
  post links to without naming the post. Typing a URL over such a link turns it back into an ordinary
  link.

## The themes

- **Paper's footer** links the site's name to its home page and "TomeCMS" to the project's repository.
- **The search field** on Paper and Plain shows one focus line instead of two.

## Testing

- The content route is covered for the owner check, the origin check, PDF-only and ready-only
  answers, and ranges (206, 416); the link's file is covered from the dialog to the delete refusal; the
  PDF thumbnail, the copied state and the full address are covered end to end.

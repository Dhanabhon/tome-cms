# TomeCMS 1.9.0

Date: 2026-10-02
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.9.0 brings six things the owner asked for while testing 1.8:
- Gemini can connect over MCP.
- The File Manager can show a list, and a file can be renamed.
- Inserting a picture no longer jumps to the top of the post.
- A picture can be replaced from the File Manager.
- Switching a plugin on or off asks first.
- Paper's reading rail makes the current heading easy to see.

`/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no migration
  and no new setting, so the updater backs up the database alone.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.9.0.

## Gemini over MCP

The Gemini web app adds a custom app with OAuth and dynamic client registration. Three things stopped
it in 1.8.2, and 1.9.0 accepts each of them.

- **Its approval goes to Google's relay.** It goes to
  `https://oauth-redirect.googleusercontent.com/r/user_bound_custom-mcp-<id>`, where the id differs
  per user and per connector. That address is now allowed when all of these hold:
  - it is `https`;
  - the host is exactly that one, with no port;
  - the id is not empty;
  - there is no query, fragment or user name.

  A code can still go only to Google's relay.
- **It registers as a client with a secret** (`client_secret_basic`).
  - It is registered as a public client instead (`none`, with PKCE). The registration answer says so,
    and no secret is issued.
  - At the token endpoint, the client id is also taken from an HTTP Basic header. Its secret part is
    ignored.
- **It asks for `offline_access`.** This is accepted and ignored, since every grant already gets a
  refresh token. Any other unknown scope is still refused.

Gemini's approval goes to Google's own host, so it shows Gemini's mark (from thesvg.org, unmodified).
The Antigravity CLI already worked through its loopback approval: `agy mcp add tomecms
https://<your-site>/mcp`.

Google currently limits custom apps in the Gemini web app to personal accounts in the US, aged 18 or
over, in English. The MCP page says so.

## The File Manager

- **Grid or list.** A switch beside the type filters shows the files as cards (the default) or as a
  list. Each row has a thumbnail, the name, the type, the size, the dimensions of an image, and the
  date. The choice is kept in this browser, and the picker in the editor has the same switch.
- **Renaming.** A file's details now include its name.
  - The file keeps its type. `photo` becomes `photo.webp`, and a name typed as only `.webp` becomes
    `.webp.webp`.
  - Posts and pages refer to a picture by its id, and the stored file does not move. So every picture
    already placed, every cover and every slide keeps working.
  - A file card in a post shows the new name after that post's next save.
  - A document downloads under the name it was uploaded with.

## Pictures in the editor

- **Inserting a picture keeps your place.** After a picture was inserted, from an upload or from the
  File Manager, the picker handed focus back to the whole editor, and the browser scrolled to its top.
  Now:
  - the page stays where it was;
  - the caret goes to the start of the line after the picture;
  - no empty line is added between two paragraphs.
- **Replace picture.** Selecting a picture shows **Replace picture**. It opens the File Manager.
  - The chosen file takes the picture's place and keeps its alignment.
  - The picture's description and name come from the new file, as a fresh insert's do.
  - One Ctrl/Cmd+Z brings the old picture back.
  - The old file stays in the File Manager.

## Plugins ask first

Switching a plugin on or off now asks, and the question says what will happen:

| Plugin | Switching on | Switching off |
|---|---|---|
| MCP | AI apps you allow can read the site and write drafts | Every connected app stops at once, and switching it on again disconnects them all |
| Turnstile | The sign-in page shows the Cloudflare check | The sign-in page stops showing it |
| Others | The plugin starts working on your site | It stops working |

Cancel leaves the switch as it was.

## Paper's reading rail

The current heading's tick is now longer (about 2.5rem for a section, 1.75rem for a subsection),
3 px thick and in the accent colour. Ticks for headings already read are ink, and those still ahead
stay muted. The tick grows from the edge nearest the text with a short transform, so nothing moves
on the page. Under reduced motion it changes at once.

  - the registration mapping and `offline_access`;

  - unique ids across all marks;

  - the client id from an HTTP Basic header, in every combination;
  - renaming, scoped to the owner, with a post's picture still rendering.
- **Browser:**
  - inserting a picture far down a post, by upload and from the File Manager, in posts and pages;
  - Replace picture, then undo and redo, then save;
  - renaming;
  - the list view at 390 and 1440 px, and in the picker;
  - the plugin confirm, cancelled and accepted;
  - the rail's current tick.

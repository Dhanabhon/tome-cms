# TomeCMS 1.5.4

Date: 2026-10-01
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.5.4 lets a link in the editor point at a picture from the File Manager, as well as a
document. `/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no
  migration and no new setting, so the updater backs up the database alone.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.5.4.

## The editor

"Choose from the File Manager" in the link dialog showed documents alone. A link may point at any file
in the library, so the picker now opens on "All", with pictures beside documents, and its type tabs
include "Images". A link to a picture works as a link to a document does: it points at the file's
address on the site, and the File Manager keeps the picture while a post or page links to it. The
picture and file blocks keep their own pickers.

## Testing

- `tests/e2e/editor-blocks.spec.ts` puts a document and a picture in the library, checks that the link
  picker opens on "All" with the picture in it, and links the document through to the delete refusal.

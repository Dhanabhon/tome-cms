# TomeCMS 1.6.1

Date: 2026-10-01
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.6.1 fixes how the language filter on Posts and Pages looks under the pointer. `/api/v1` is
unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no
  migration and no new setting, so the updater backs up the database alone.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.6.1.

## The admin

The language filter at the end of the status tabs on Posts and Pages is a select without a box. Under
the pointer it took the grey fill every boxed field has, so its words sat at the edge of a grey block
that covered the tabs' rule, and a press drew a line under it like the current tab's. Under the
pointer, and while its list is open, its words now darken instead, and a press draws nothing.

## Testing

- Two "refused at once" tests of the Markdown reader, for a block with too many lines, failed the
  1.6.0 release job on its slower runner (5.8–6.2 s against 5 s). Counting a block's lines runs
  marked's block lexer, which is slower than linear on a long list, so they now get the 15 s bound
  the HTML refusals have; in production the worker's time limit bounds them either way.

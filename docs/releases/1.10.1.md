# TomeCMS 1.10.1

Date: 2026-10-02
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.10.1 makes header sub-menus easy to arrange. In 1.10.0 an item was nested with ← → buttons,
which the owner found hard to follow. Now you drag it where it should go. `/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no migration
  and no new setting, so the updater backs up the database alone.
- **Updater 1.4.0** also removes the older application images after this update. It keeps the
  installed image and the one before it.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.10.1.

## Arranging the menu by dragging

On the Navigation screen, drag a row by its grip (⋮⋮). It works with a mouse, a finger or a pen.
- **Onto the middle of a main-menu item:** the row goes into that item's sub-menu, as its last
  item. The item lights up while you aim.
- **Onto the top or bottom edge of a main-menu item:** the row goes above or below it, in the main
  menu. Below an item with a sub-menu means after its whole sub-menu.
- **Onto the edge of a sub-item:** the row goes above or below it, in the same sub-menu. This also
  moves a sub-item from one sub-menu to another.
- A line above the list says what the drop will do, or why it can't. Some drops are refused:
  - an item that has a sub-menu cannot go into another one, because there is only one level;
  - a group always stays in the main menu.
- Escape cancels a drag.
- Near the top or bottom of the window, the page scrolls.
- A main-menu item moves together with its sub-menu.
- The Footer stays flat, so there you can only drag above or below.

The ← → buttons are gone. For the keyboard and screen readers, each header row has a ⋯ button,
"Sub-menu options", with the two moves that apply to that row:
- "Put under {the main-menu item above}";
- "Move out to the main menu".

Move up, Move down and Remove are as before.

- **Unit:**

  - every combination of rows on three sample menus, checked by the reviewer.
- **Browser:**
  - dragging into a sub-menu, out to the main menu, and a refused drop with its message;
  - the Footer;
  - the ⋯ menu by keyboard;
  - saving and reloading;
  - a real touch drag at 390 px;
  - the label fields lining up on every row;
  - Home slides unchanged.

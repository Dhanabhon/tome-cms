# TomeCMS 1.6.2

Date: 2026-10-01
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.6.2 lets the owner ask the suggester for another sentence when the first one does not suit.
`/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes. There is no
  migration and no new setting, so the updater backs up the database alone.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.6.2.

## Another suggestion

With a suggester plugin on (Jev), "Suggest a line from the text" and "Suggest a description from the
text" offer one sentence from the post. Pressing either again usually brought back the same sentence:
the plugin chooses from the same list each time.

A suggested sentence now has "Another one" (ขอประโยคอื่น) beside "Use this line". It sends every
sentence shown since the main button was pressed, and the server leaves those out of the list before
the plugin chooses, so the next one is always new. When no sentence is left, the drawer says so and the
next press starts over. The main button always starts a new round.

The plugin contract is unchanged: a suggester still picks from the passages it is offered, and the core
still keeps its pick only if it was one of them. `POST /api/admin/suggest-excerpt` takes an optional
`exclude`, at most 20 passages of at most 320 characters each.

## Testing

- Integration: a shown passage is not offered to the plugin again, the next pick is another passage, and
  with every passage shown the answer is none and nothing is sent.
- Browser: "Another one" sends what was shown, ends the round when nothing is left, and the main button
  starts a new one.

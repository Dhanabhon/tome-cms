# TomeCMS 1.20.0

Date: 2026-10-07
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.20.0 draws each picture from a copy that fits the screen, gives every category a page
of its own, and fixes a few small things around adding a device. `/api/v1` and MCP only gain a
field.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. This release has one migration,
  `033_media_variants_and_category_pages`, so the updater takes a full backup (database and
  media) before it applies it. The migration gives every existing category an address made from
  its name (`-2`, `-3` when two names make the same one).
- **A build from source** upgrades in place by running the deploy helper again; it runs the
  migration.
- **The updater** stays at 1.6.0. Nothing to upgrade on the server.
- **After the update**, the site makes smaller copies of the images it already has, in the
  background, oldest first and one at a time. On a small server with a large library this takes a
  while and uses some CPU; pages show the original until an image has its copies. The log ends the
  walk with one line: "Images were given their smaller copies." with the counts, or a line saying
  it stopped and that the next start tries again.
- **Storage** grows by about three small WebP files per image, and each backup by the same.
- **If an update rolls back to 1.19.x**, the site keeps working, but an image deleted under 1.19
  leaves its copies in the bucket, and `reset --execute` then refuses the bucket. Update to 1.20.0
  again before deleting images.
- **A theme of your own** forked before 1.20.0 keeps working. To link its category chips to the
  new pages and keep its "older posts" link on them, see "For theme authors" below.

`deploy/cloud-init.yaml` now installs 1.20.0.

## Added

- **Pictures at the size they are drawn.** Every image uploaded or imported gets WebP copies 480,
  960 and 1600 pixels wide (only the widths narrower than the original; none for an animated
  image). Pages list them with `srcset` and a `sizes` that matches each theme's column, so a phone
  loads a small copy and a wide screen a large one: pictures in a post or page, covers, home
  cards and slides, in Paper, Plain and Almanac. The full-size view still opens the picture at
  full size. `/media/<id>?w=480`, `960` or `1600` answers with that copy, or with the original
  when there is none. A copy that cannot be made never stops an upload.
- **A page for every category.** `/th/category/<address>` and `/en/category/<address>` list that
  category's posts in the theme's own home layout, with their own title, description, canonical
  address, languages, later pages and breadcrumb (Home › Category). Category names on chips and
  on posts link to them, and the sitemap lists them. "Uncategorized" has no page, and a category
  answers "not found" in a language where it has no published post.
- **A category's address and description.** The category manager edits a category's URL name
  (Thai allowed) and a description in Thai and in English, up to 160 characters each. Renaming a
  category keeps its address; changing the URL name moves the page, and old links to the previous
  address stop working. The page's description borrows the other language's when its own is
  empty.
- **Breadcrumbs through the category.** A post's breadcrumb is Home › its first category ›
  the post (Home › the post when it has only "Uncategorized").

## Changed

- **Old category links** (`/th?category=<name>`) answer with a permanent redirect to the
  category's page when that page exists. A link from a search, a link to "Uncategorized", and a
  theme's "older posts" link keep working as before.
- **Sideways photos are measured the way they are seen.** A phone photo turned by its EXIF
  orientation is stored with its upright width and height; the background walk corrects images
  uploaded before.
- **`/api/v1` and MCP** list each category's `slug`, on its own and inside a post. `/api/v1`'s
  site description is the default language's, or the other language's when that one is empty.
- **Export and import** carry each category's address and descriptions. An archive from before
  1.20.0 still imports; its categories get addresses from their names. `tome import` makes the
  smaller copies of the pictures it brings in before it finishes.
- **Creating a device link** has its own limit (10 in 15 minutes) instead of sharing the sign-in
  one, so making a few links cannot lock the owner out of signing in.

## Fixed

- **`/add-device`** says the link has expired, instead of "server error", when the link is
  cancelled, replaced, used by a recovery code or runs out between the two steps. A recovery link
  that dies the same way says the passkey was not created.
- **The Security screen** counts a device link's time from the server's answer, not from the
  computer's clock, and ends a link at once when you come back to a computer that slept past it.
- **The category manager** ties its errors and hints to their fields for screen readers, and two
  messages that showed in English in the Thai admin are now in Thai.

## For theme authors

- `Home` receives an optional `category` (name, address, description) on a category page.
- Build pagination links with `listHref`, category links with `categoryHref`, and a cover's
  `srcset`/`sizes` with `responsiveAttrs`. A theme that builds `?category=<name>&cursor=…` links
  itself keeps working; those links are not redirected.
- `articleCover(post, sizes)` takes the `sizes` for the article column; a theme that passes only
  `post` gets `100vw`.

## Testing

- **Unit:** copy widths for 400 to 4000-pixel images, none for an animated one, no metadata in a
  copy; EXIF orientations 1 to 8; the `?w=` choice; the `srcset` and `sizes` strings and the CSS
  they follow; the body rewrite with alt texts, titles, the lead image and links; category page
  titles, descriptions, redirects, breadcrumbs, sitemap entries and Thai addresses; the
  device-link countdown.
- **Integration:** copies stored, deleted, cleaned up and counted by reset; the background walk
  and where it resumes; category addresses made, kept, edited and refused; the migration's fill;
  export and import with and without addresses; `tome import` waiting for its copies; the API's
  `slug`.
- **Browser:** a post's pictures and cover carry `srcset` in each theme; the full-size view opens
  the original; a category page per theme with its title, canonical address, languages,
  breadcrumb and later pages; old links redirect; "Uncategorized" and unknown addresses are not
  found; the category manager; a device link that dies between the two steps.
- **Operations:** the managed update, a fresh install and a restore, with the migration.

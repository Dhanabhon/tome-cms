# TomeCMS 1.17.1

Date: 2026-10-06
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.17.1 makes the "Add a device" card notice the new device by itself. `/api/v1` is
unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration, so the updater backs up the database
  alone. An install still on 1.16.4 or older gets 1.17.0's one migration, `030_device_enrollment`,
  on the way.
- **A build from source** upgrades in place by running the deploy helper again.
- **The updater** stays at 1.6.0. Nothing to upgrade on the server.

`deploy/cloud-init.yaml` now installs 1.17.1.

## Fixed

- **The Security screen sees the new device come in.** In 1.17.0 the card looked again only when
  its window came back to the front. The owner holding the other device never leaves the window,
  so the link and its QR code stayed up after the device had its passkey. Now, while a link shows,
  the card checks every few seconds (only while its tab is on screen, and at once when you come
  back to it):
  - it says "Waiting for the other device…" with a small breathing dot, so a link left up does
    not look stuck;
  - when the device comes in, the link and QR code go, the card names it ("Added iPhone. Its
    passkey is in the list above."), and its row in the list lights up for a moment;
  - when the link runs out unused, the card says it expired before a device used it, and
    "Create a link" is back.

  The card cannot see a failure on the other device, such as a cancelled passkey prompt: that
  device says so itself, and the link keeps working until it is used or expires.

## Testing

- **Browser:** a signed-in owner makes a link and, without the window ever losing focus, a second
  browser opens it and creates a passkey; the first card notices within seconds, names the
  device in the card, marks its row, and the link and QR code are gone.

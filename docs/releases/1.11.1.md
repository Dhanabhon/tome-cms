# TomeCMS 1.11.1

Date: 2026-10-03
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.11.1 rearranges Almanac's header and footer, following the owner's reference page more
closely. `/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration, so the updater backs up the database
  alone.
- **A build from source** upgrades in place by running the deploy helper again.
- **The updater** stays at 1.5.0. Nothing to upgrade on the server.

`deploy/cloud-init.yaml` now installs 1.11.1.

## Almanac

**Header.**
- The site's name, with the menu right beside it on the left. Sub-menus work as before.
- A search box on the right, which searches posts from any page.
- On a phone: the name and Menu on the left, and a search button on the right that opens the
  search box in place.

**Footer.**
- On the left, on one line: "© year site name • Powered by TomeCMS". Only the © part shows when
  "Powered by" is switched off.
- On the right, in this order:
  1. the footer menu, if you have set one;
  2. the language switch;
  3. the light and dark switch.

**Home page.** The category pills stay; the search box has moved up into the header.

## Testing

- **Browser:**
  - the header order and search, from the home page and from a post;

  - the footer line, with and without "Powered by";

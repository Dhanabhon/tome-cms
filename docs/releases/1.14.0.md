# TomeCMS 1.14.0

Date: 2026-10-04
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.14.0 is a design release. The three themes and the admin were reviewed screen by screen,
in English and Thai, light and dark, from a phone to a wide screen, and this release does what that
review asked for. `/api/v1` is unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration, so the updater backs up the database
  alone.
- **The updater** stays at 1.6.0. Nothing to upgrade on the server.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.14.0.

## Paper

- **Look:**
  - The page is warm paper instead of white.
  - Cards sit on thin rules instead of rounded boxes.
  - Pictures have square corners.
  - Everything, Thai included, is set in Google Sans.
- **A post without a cover** shows its category on a quiet panel, instead of a large letter.
- **Choosing a category or searching** hides the slides and names what you are looking at.
- **Slide words:**
  - On a phone or a tablet, the words sit under the picture, so the whole picture shows.
  - On a wide screen, they sit over its lower part on a soft shade that keeps them readable.
- **Reading:** post text keeps to a comfortable line length.
- **On a phone:** the site's name is no longer cut off, the language button shows "EN" or "TH", and
  buttons and links are easy to tap.

## Almanac

- **A post without a cover** shows a band in its category's colour, with the category's name. On a
  category's own page the band carries the colour alone.
- **Choosing a category** hides the hero, so the posts come first.
- **The hero heading.** With no hero headline set, the hero's heading is the site's tagline instead of
  the site's name, which the header already shows.
  - The tagline is one setting for all languages, so a Thai page shows it as written.
  - Set a hero headline under Appearance → Themes → Almanac to choose the words.
- **Post text** keeps to a comfortable line length, a post's title on a phone is clearly larger than
  its headings, and emphasis shows as a slightly heavier weight, not italics.
- **Cards** answer the pointer with one quiet change instead of four, and buttons no longer wrap to
  two lines.

## Plain

- **Plain is set in Google Sans,** so Thai looks the same on every device.
- **The category row** is one line you can scroll on a phone. The chosen category stays in view,
  also when you move to it with the keyboard.
- **Empty states.** A site with no posts, an empty category and a feed that fails to load each say
  so, instead of showing a blank page.
- **Paging.** "More posts" leads to the next page, and "Latest posts" back to the first.
- **Post text** keeps to a comfortable line length, and code sits between two rules.

## All themes

- **A missing page** is drawn in the theme's own type and lines up with its content, instead of a
  centred block in one fixed style.
- **Inline code** no longer shows backticks around it.
- **Buttons and links** respond to a press, and hover effects no longer stick after a tap on a phone.
- **The lightbox** opens at its picture's shape straight away, instead of an empty frame while a large
  picture loads.

## The admin

The admin follows its own design guide again:
- **One main action per screen.** A screen shows one green button. A form's Save turns green once
  there is something to save.
- **Selection** is shown by text colour and an underline, never by a filled background.
- **Notes and banners** no longer carry a coloured bar down one edge.
- **Menus** that drop down from a field have a shadow.
- **Fields** keep a line for their error message, so the form does not jump when one appears.
- **Stats.** Language is a menu, the periods read 7d, 30d, 90d and 12m, and a period with no visits
  shows one message instead of empty panels.
- **System** shows the installed version straight away.

## For theme authors

- **`preloadFonts`.** A theme's manifest may list `preloadFonts`: the fonts its first screen draws,
  as `/fonts/<file>.woff2` paths directly in `public/fonts/`.
  - The page preloads exactly that list. A theme that lists none preloads none. TomeCMS no longer
    preloads any font of its own on a theme's pages.
  - `tome check` refuses a path that is not a `.woff2` file there.
  - `tome theme new` copies the list.
  - See [Themes](https://dhanabhon.github.io/tome-cms/extending/themes/).
- **The language switcher** takes the type size and weight of the place it sits in. A theme that
  wants it smaller or bolder sets that on the surrounding element.
- **The missing page's title** now uses the theme's `--font-display` and the article-title scale.
  The `.notice-title` class is gone.
- **The `--ease-spring` token is removed.** Overlays move with `--ease-out`.

## Testing

- **New unit tests** pin each change in the themes' and the admin's stylesheets: line lengths,
  hover only where a pointer can hover, no filled backgrounds for selection, the fonts each theme
  uses and preloads, and the `tome check` rule.
- **Browser tests:**
  - a category view in each theme;
  - Plain's category row by keyboard;
  - Paper's slide words, measured at 4.5:1 or better;
  - one main action on every admin screen, in every state.
- **A new screenshot instrument** shoots every theme screen at four widths, in light and dark and in
  Thai. It was run before and after this release, and a second design review of the "after" set
  checked every finding of the first.

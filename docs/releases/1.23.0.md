# TomeCMS 1.23.0

Date: 2026-10-12
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.23.0 lets you drag files from your computer onto the file library to upload them into the
folder you have open.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration; the latest is still
  `034_default_category_name`.
- **The updater and `tome`** are unchanged. Nothing to upgrade on the server.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.23.0.

## Added

- **Drag and drop on the file library.** Drag files from your computer onto the list of files: an
  outline names the folder they will go to (the one you have open, or "Unsorted" when "All files"
  or "Unsorted" is selected). Drop them and the usual upload window opens with that folder chosen.
  Nothing is uploaded until you press its Upload button; you can still remove files or pick another
  folder first, and each file shows its progress as it goes up.
  - Folders dragged from your computer are skipped, and the window says how many. Drop the files
    inside a folder rather than the folder itself.
  - While any window is open on the page (an upload, a file's details, a confirmation), a drop does
    nothing.
  - A file dropped anywhere on the page no longer replaces the admin in the browser tab.
  - The Upload files button, the keyboard and phones work as before. The picker you use while
    writing does not take drops yet.

## Fixed

- **A list opened while its window was still sliding in** was placed against the moving window and
  could open off the screen. It now settles beside its field once the window has arrived, in every
  window of the admin, and so does the date and time picker.

## Testing

- **Unit:** what a drag carries, which dropped items are files and which are folders, and the
  folder the outline names.
- **Browser:** files dragged into a folder open the upload window with that folder chosen, nothing
  is uploaded before the button, and both files land in the folder; text drags, leaving the page,
  Escape, and drops while a window is open change nothing. A list opened mid-entrance (animations
  slowed tenfold) ends beside its field, ten times in a row. The full suite.
- **Operations:** the managed update and a restore.

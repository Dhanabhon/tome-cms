# TomeCMS 1.25.0

Date: 2026-11-03
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.25.0 lets a page show a list of posts, hand-picked or from a category, as a grid or a list.
It also updates the libraries that had published security advisories.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration; the latest is still
  `034_default_category_name`.
- **The updater and `tome`** are unchanged. Nothing to upgrade on the server.
- **A build from source** upgrades in place by running the deploy helper again.

`deploy/cloud-init.yaml` now installs 1.25.0.

**Going back to an older image:** versions before 1.25.0 do not know the block, and going back with
pages that hold one has not been tested. Keep a backup from before you add the first block.

## Added

- **Post list block.** In a page's editor, the `+` menu or `/` adds a post list anywhere in the body, as
  many as the page needs. The
  [Pages and menus](https://dhanabhon.github.io/tome-cms/admin/pages-and-menus/) guide has the details.
  - **Source:** posts you pick, in your order, or a whole category, newest first. Each block holds up
    to 24 posts; a category starts at 6.
  - **Layout:** a grid of 2 or 3 columns, or a list. A column count is a maximum, so narrow screens use
    fewer and phones one.
  - **Cards** are the ones on that theme's home page. Plain's have no cover, so its grid is text only.
  - **"See all"** links to the category page when the category holds more than the block shows.
  - **Languages:** each language's page holds its own block, which shows the edition in that language
    and skips posts without one.
  - **Missing posts:** deleting or unpublishing a post is never blocked. The public page leaves it out,
    and the editor says what no longer shows.
  - **Export and import** keep the blocks and repoint them at the new ids. The readable `.md` gets a
    short note in place of the block.
  - **MCP:** an agent sees a block as `{{tome:block N}}` and can move or remove it, not create or edit
    one.

Posts do not offer the block, and saving one that holds it is refused with a plain message.

## Security

`npm audit` now reports nothing. These were updated:

- **`better-auth` and `@better-auth/passkey` 1.7.3 to 1.7.15.** The critical advisory is the OAuth
  Proxy plugin letting an attacker sign in as another user. TomeCMS signs in with passkeys and does
  not use that plugin. The auth tables are unchanged.
- **`@modelcontextprotocol/server` 2.2.0 to 2.4.0.** The advisories cover messages reaching the wrong
  client on a shared transport, and memory exhaustion. TomeCMS's `/mcp` endpoint uses this library.
- **`sanitize-html` to 2.18.1.** The advisories cover ways past its filtering. TomeCMS runs stored
  content through it.
- **`zod`, `vite`, `undici`, `deepmerge` and `fast-uri`** to fixed versions.

## Testing

- **Unit:** the block's attributes and what it refuses, export, import and MCP handling.
- **Integration:** a block resolves only to posts a reader may see; a post refuses a block and a page
  keeps one; import repoints blocks.
- **Browser, on all three themes:** text and lists in order, two blocks in a row, a block that shows
  nothing, "see all", columns, and no sideways scroll with a long Thai title.
- **Browser, in the editor:** inserting from the `+` menu and `/`, picking and reordering, the 24-post
  limit, undo, dragging a block, a deleted post, and a post editor that offers no block. The full suite,
  on the updated libraries.
- **Visual:** the Paper and Plain home pages match the previous code pixel for pixel at 320, 768, 1024
  and 1440 px, light and dark, because their cards moved into shared parts.

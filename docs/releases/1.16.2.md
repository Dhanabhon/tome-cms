# TomeCMS 1.16.2

Date: 2026-10-05
Status: Stable release; tagged and published as a GitHub release

TomeCMS 1.16.2 fixes small things left over from the reviews of 1.15 and 1.16. `/api/v1` is
unchanged.

## Upgrading

- **A managed install** updates from "System" in the admin, as
  [Updating](https://dhanabhon.github.io/tome-cms/running/updating/) describes, or with
  `sudo tome update` on the server. There is no migration, so the updater backs up the database
  alone.
- **A build from source** upgrades in place by running the deploy helper again.
- **The updater** stays at 1.6.0. Nothing to upgrade on the server.

`deploy/cloud-init.yaml` now installs 1.16.2.

## Fixed

- **A page that could not read its menu or slides is not kept.** When the database is slow (for
  example a busy 1 GB server), the menu or home slides can fail to load while a page is drawn. The
  page still reaches that reader without them. Before, the page cache from 1.16.0 kept that
  incomplete page and showed it to everyone for up to five minutes. Now it is never kept, the next
  reader gets a whole page, and the incomplete one is sent with `Cache-Control: no-store` so no
  browser or CDN keeps it either.
- **Draft previews describe old pictures the way the site does.** A picture saved with its file name
  as alt text shows the media library's description, or none, in the admin's draft preview, as it
  already did on the site since 1.16.1.

## Testing

- **Unit:**
  - an incomplete page is served but never kept;
  - the flag that marks it belongs to one request only;
  - it is still caught when the failed read happens while the page is streaming.
- **Integration:**
  - a failed menu or slides read marks the page;
  - a draft preview gets the library's alt text.
- **Browser:**
  - **Touch targets on a tablet.** The checks also run at 768 pixels with a touch screen, and fail if
    anything scrolls sideways.
  - **Touch targets in the editor.** They are also measured with each of the editor's open states:
    the picture and table bars, the slash menu, the link dialog, the settings drawer, the media
    picker and the folder menu. Every control already measured at least 44 by 44 pixels, so no style
    changed.
  - **Theme screenshots.** The instrument clears the page cache between themes. Since 1.16.0 it had
    been shooting every theme as Paper.
